
# n8n 기본 사용법

n8n은 코드 없이 워크플로우를 구축할 수 있는 오픈소스 워크플로우 자동화 도구입니다. 아래에 기본적인 사용법을 상세히 설명해 드리겠습니다.

## 1. n8n 설치 및 실행

### Docker로 설치 (가장 일반적인 방법)
```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

### npm으로 설치
```bash
npm install n8n -g
n8n
```

## 2. 기본 인터페이스 이해

n8n에 접속하면(기본적으로 http://localhost:5678) 다음과 같은 주요 구성 요소를 볼 수 있습니다:

- **워크플로우 캔버스**: 워크플로우를 구성하는 공간
- **노드 패널**: 사용 가능한 모든 노드 목록
- **속성 패널**: 선택한 노드의 설정을 변경하는 공간

## 3. 첫 번째 워크플로우 만들기

### 단계 1: 트리거 노드 추가
1. 왼쪽 노드 패널에서 "Trigger" 카테고리를 선택
2. "Manual Trigger"를 캔버스로 드래그 앤 드롭
3. 이 노드는 워크플로우를 수동으로 시작하는 역할을 합니다

### 단계 2: 작업 노드 추가
1. 노드 패널에서 "Core" 카테고리 선택
2. "Set" 노드를 캔버스로 드래그
3. Manual Trigger 노드의 오른쪽에 있는 점을 클릭하고 Set 노드로 연결

### 단계 3: 노드 구성
1. Set 노드를 클릭하여 속성 패널 열기
2. "Add Value" 버튼 클릭
3. Name에 "message", Value에 "Hello World!" 입력

### 단계 4: 결과 확인 노드 추가
1. "Core" 카테고리에서 "Debug" 노드 추가
2. Set 노드와 Debug 노드 연결
3. Debug 노드에서 "Output" 옵션 선택

### 단계 5: 워크플로우 실행
1. 오른쪽 상단의 "Execute Workflow" 버튼 클릭
2. Debug 패널에서 결과 확인

## 4. 일반적인 노드 유형

### 트리거 노드
- **Schedule**: 정해진 시간에 워크플로우 실행
- **Webhook**: 외부 요청을 받아 워크플로우 실행
- **Polling**: 주기적으로 데이터 확인

### 작업 노드
- **HTTP Request**: API 호출
- **Code**: JavaScript/Python 코드 실행
- **Function**: 사용자 정의 함수 작성
- **Spreadsheet**: Google Sheets 연동

## 5. 데이터 처리 방법

n8n에서는 `{{ }}` 문법으로 데이터를 참조할 수 있습니다:

- `{{ $json }}`: 현재 노드의 전체 입력 데이터
- `{{ $json.fieldName }}`: 특정 필드 값
- `{{ $nodeName.json }}`: 다른 노드의 데이터 참조

## 6. 에러 처리

- **Error Trigger**: 워크플로우 에러를 감지
- **IF 노드**: 조건에 따라 다른 분기 실행
- **Retry 기능**: 노드 실패 시 재시도 설정

## 7. 워크플로우 관리

- **임포트/익스포트**: JSON 형식으로 워크플로우 저장 및 공유
- **활성화/비활성화**: 필요에 따라 워크플로우 실행 제어
- **실행 기록**: 과거 실행 결과 확인

## 8. 실용적인 예제: 이메일 자동화

1. **Schedule Trigger** 추가 (매일 오전 9시 설정)
2. **HTTP Request** 노드 추가 (API에서 데이터 가져오기)
3. **IF** 노드 추가 (특정 조건 확인)
4. **Email** 노드 추가 (조건 충족 시 이메일 발송)

## 9. 팁과 모범 사례

- 노드에 의미 있는 이름 지정
- 복잡한 워크플로우는 주석 노드로 설명 추가
- 테스트용으로 Debug 노드 활용
- production 환경에서는 적절한 자격 증명 관리 사용

n8n은 200개 이상의 통합 노드를 제공하며, 커뮤니티에서 지속적으로 새로운 노드가 추가되고 있습니다. 공식 문서와 포럼에서 더 많은 정보와 예제를 찾아볼 수 있습니다.
