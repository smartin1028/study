# 로컬 환경에 n8n 설치 및 사용 가이드

n8n은 코드 없이 워크플로우를 구축할 수 있는 오픈소스 워크플로우 자동화 도구입니다. 로컬 환경에 설치하고 사용하는 방법을 상세히 설명드리겠습니다.

## 설치 방법

### 1. Docker를 이용한 설치 (가장 쉬운 방법)

```bash
# 기본 설치
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n

# 백그라운드 실행 및 데이터 영구 저장
docker run -d \
  --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  n8nio/n8n
```

### 2. npm을 이용한 설치

```bash
# n8n 설치
npm install n8n -g

# n8n 실행
n8n
```

### 3. Windows에서의 설치

```bash
# PowerShell 또는 CMD에서
npm install n8n -g
n8n
```

## 기본 사용법

### 1. n8n 접속
설치 후 웹 브라우저에서 `http://localhost:5678`로 접속합니다.

### 2. 첫 번째 워크플로우 생성하기

1. **새 워크플로우 생성**: 왼쪽 사이드바에서 "Workflows" → "New Workflow" 클릭
2. **트리거 설정**: "Add first step" 클릭 후 원하는 트리거 선택 (예: Schedule, Webhook, Manual)
3. **액션 추가**: "+" 버튼으로 새로운 노드 추가
4. **노드 연결**: 노드 사이를 드래그하여 연결
5. **설정 저장**: 오른쪽 상단 "Save" 버튼 클릭

### 3. 기본 노드 예제: HTTP 요청 + 이메일 전송

```javascript
// 간단한 JavaScript 코드 예제 (Code 노드에서 사용)
const response = await $axios.$get('https://api.example.com/data');
return { json: response };
```

## 환경 설정

### 구성 파일 설정
`~/.n8n/config` 파일 생성 또는 환경 변수로 설정:

```bash
# 기본 포트 변경
export N8N_PORT=5678

# 암호화 키 설정
export N8N_ENCRYPTION_KEY=your-encryption-key

# 데이터베이스 설정 (기본 SQLite)
export DB_TYPE=sqlite
export DB_SQLITE_VARCHAR_MAX_LENGTH=16384
```

## 자주 사용하는 노드 종류

1. **트리거 노드**: Schedule, Webhook, Manual Trigger
2. **액션 노드**: HTTP Request, Email, Slack, Discord
3. **데이터 처리 노드**: Function, Set, Split In Batches
4. **플랫폼 노드**: Google Sheets, Airtable, Notion, Telegram

## 고급 기능

### 워크플로우 예제: 주기적 데이터 수집 및 알림

1. **Schedule Trigger**: 매일 오전 9시 실행 설정
2. **HTTP Request**: 외부 API에서 데이터 가져오기
3. **Function**: 데이터 가공 및 필터링
4. **If**: 조건에 따른 분기 처리
5. **Email**: 결과 이메일로 전송

### 커스텀 노드 개발

```bash
# n8n 노드 개발자 도구 설치
npm install -g n8n-node-dev

# 새 노드 생성
n8n-node-dev new
```

## 문제 해결

### 일반적인 문제점 및 해결 방법

1. **포트 충돌**: `-p 5678:5678`에서 포트 번호 변경
2. **권한 문제**: Docker에서는 `-u $(id -u):$(id -g)` 추가
3. **저장 공간**: `-v` 옵션으로 볼륨 마운트 확인

### 로그 확인

```bash
# Docker 로그 확인
docker logs n8n

# 직접 설치 시 로그
n8n start --verbose
```

# 워크플로우 내보내기
# UI에서 워크플로우 선택 → Export 클릭

## 보안 설정

```bash
# 기본 인증 설정
export N8N_BASIC_AUTH_ACTIVE=true
export N8N_BASIC_AUTH_USER=사용자명
export N8N_BASIC_AUTH_PASSWORD=비밀번호
```

이 가이드를 통해 로컬 환경에 n8n을 성공적으로 설치하고 기본적인 사용법을 익힐 수 있을 것입니다. n8n은 다양한 통합과 커스텀 기능을 제공하므로 공식 문서를 참조하여 더 복잡한 워크플로우를 구축할 수 있습니다.
