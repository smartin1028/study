Java에서 Jackson ObjectMapper를 사용하여 JSON 문자열을 Map으로 변환하는 방법에 대해 상세히 설명드리겠습니다.

## 1. 기본적인 사용법

### 의존성 추가 (Maven)
```xml
<dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.15.0</version>
</dependency>
```

### 기본 변환 코드
```java
import com.fasterxml.jackson.databind.ObjectMapper;
import java.util.Map;

public class JsonToMapExample {
    public static void main(String[] args) {
        ObjectMapper objectMapper = new ObjectMapper();
        
        String jsonString = "{\"name\":\"John\", \"age\":30, \"city\":\"New York\"}";
        
        try {
            // JSON 문자열을 Map으로 변환
            Map<String, Object> resultMap = objectMapper.readValue(jsonString, Map.class);
            
            System.out.println("Name: " + resultMap.get("name"));
            System.out.println("Age: " + resultMap.get("age"));
            System.out.println("City: " + resultMap.get("city"));
            
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

## 2. 다양한 변환 방법

### TypeReference 사용 (권장)
```java
import com.fasterxml.jackson.core.type.TypeReference;
import java.util.Map;

// 더 정확한 타입 추론을 위해 TypeReference 사용
Map<String, Object> resultMap = objectMapper.readValue(
    jsonString, 
    new TypeReference<Map<String, Object>>() {}
);
```

### 특정 타입의 Map 사용
```java
import java.util.HashMap;
import java.util.LinkedHashMap;

// HashMap으로 변환
HashMap<String, Object> hashMap = objectMapper.readValue(
    jsonString, 
    new TypeReference<HashMap<String, Object>>() {}
);

// LinkedHashMap으로 변환 (순서 보존)
LinkedHashMap<String, Object> linkedHashMap = objectMapper.readValue(
    jsonString, 
    new TypeReference<LinkedHashMap<String, Object>>() {}
);
```

## 3. 중첩된 JSON 처리

```java
String nestedJson = """
{
    "user": {
        "name": "John",
        "details": {
            "age": 30,
            "email": "john@example.com"
        }
    },
    "roles": ["admin", "user"]
}
""";

Map<String, Object> nestedMap = objectMapper.readValue(
    nestedJson, 
    new TypeReference<Map<String, Object>>() {}
);

// 중첩된 값 접근
Map<String, Object> userMap = (Map<String, Object>) nestedMap.get("user");
Map<String, Object> detailsMap = (Map<String, Object>) userMap.get("details");
List<String> roles = (List<String>) nestedMap.get("roles");

System.out.println("Email: " + detailsMap.get("email"));
```

## 4. ObjectMapper 설정 커스터마이징

```java
import com.fasterxml.jackson.databind.DeserializationFeature;

ObjectMapper customMapper = new ObjectMapper();

// 알 수 없는 속성 무시
customMapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);

// 빈 문자열을 null로 처리
customMapper.configure(DeserializationFeature.ACCEPT_EMPTY_STRING_AS_NULL_OBJECT, true);

// 날짜 형식 설정
customMapper.setDateFormat(new SimpleDateFormat("yyyy-MM-dd"));

Map<String, Object> customMap = customMapper.readValue(jsonString, Map.class);
```

## 5. 예외 처리

```java
import com.fasterxml.jackson.core.JsonProcessingException;

public Map<String, Object> parseJsonToMap(String jsonString) {
    ObjectMapper objectMapper = new ObjectMapper();
    
    try {
        return objectMapper.readValue(jsonString, new TypeReference<Map<String, Object>>() {});
    } catch (JsonProcessingException e) {
        System.err.println("JSON 파싱 오류: " + e.getMessage());
        return Collections.emptyMap();
    } catch (Exception e) {
        System.err.println("기타 오류: " + e.getMessage());
        return Collections.emptyMap();
    }
}
```

## 6. 실용적인 유틸리티 메서드

```java
import java.util.Map;
import java.util.List;

public class JsonUtils {
    private static final ObjectMapper objectMapper = new ObjectMapper();
    
    static {
        objectMapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);
    }
    
    // JSON 문자열을 Map으로 변환
    public static Map<String, Object> jsonToMap(String json) {
        try {
            return objectMapper.readValue(json, new TypeReference<Map<String, Object>>() {});
        } catch (Exception e) {
            throw new RuntimeException("JSON to Map 변환 실패", e);
        }
    }
    
    // Map을 JSON 문자열로 변환
    public static String mapToJson(Map<String, Object> map) {
        try {
            return objectMapper.writeValueAsString(map);
        } catch (Exception e) {
            throw new RuntimeException("Map to JSON 변환 실패", e);
        }
    }
    
    // 특정 키의 값을 가져오는 헬퍼 메서드
    public static <T> T getValue(Map<String, Object> map, String key, Class<T> clazz) {
        Object value = map.get(key);
        return clazz.isInstance(value) ? clazz.cast(value) : null;
    }
}
```

## 7. 사용 예제

```java
public class Main {
    public static void main(String[] args) {
        String json = """
        {
            "name": "John Doe",
            "age": 30,
            "isActive": true,
            "hobbies": ["reading", "swimming"],
            "address": {
                "street": "123 Main St",
                "city": "Seoul"
            }
        }
        """;
        
        Map<String, Object> data = JsonUtils.jsonToMap(json);
        
        // 값 접근
        String name = JsonUtils.getValue(data, "name", String.class);
        Integer age = JsonUtils.getValue(data, "age", Integer.class);
        List<String> hobbies = JsonUtils.getValue(data, "hobbies", List.class);
        Map<String, Object> address = JsonUtils.getValue(data, "address", Map.class);
        
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        System.out.println("Hobbies: " + hobbies);
        System.out.println("City: " + address.get("city"));
    }
}
```

## 주의사항

1. **TypeReference 사용**: `Map.class` 대신 `TypeReference`를 사용하는 것이 타입 안정성에 더 좋습니다.
2. **예외 처리**: 항상 적절한 예외 처리를 통해 JSON 파싱 실패에 대비하세요.
3. **성능**: ObjectMapper는 thread-safe하므로 재사용하는 것이 좋습니다.
4. **타입 캐스팅**: Map에서 값을 꺼낼 때는 적절한 타입 캐스팅이 필요합니다.

이러한 방법들을 통해 JSON 문자열을 효과적으로 Map으로 변환하고 활용할 수 있습니다.
