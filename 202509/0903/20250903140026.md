Kibana를 로컬 환경에서 로그 분석기로 구축하는 방법에 대해 상세히 설명드리겠습니다.

## 1. 필수 구성 요소 설치

### Elasticsearch 설치
```bash
# Docker로 설치 (권장)
docker pull docker.elastic.co/elasticsearch/elasticsearch:8.11.0
docker run -d --name elasticsearch -p 9200:9200 -p 9300:9300 -e "discovery.type=single-node" docker.elastic.co/elasticsearch/elasticsearch:8.11.0

# 또는 직접 설치
# https://www.elastic.co/downloads/elasticsearch
```

### Kibana 설치
```bash
# Docker로 설치
docker pull docker.elastic.co/kibana/kibana:8.11.0
docker run -d --name kibana --link elasticsearch:elasticsearch -p 5601:5601 docker.elastic.co/kibana/kibana:8.11.0

# 또는 직접 설치
# https://www.elastic.co/downloads/kibana
```

## 2. 기본 설정

### Kibana 구성 파일 수정 (config/kibana.yml)
```yaml
server.port: 5601
server.host: "localhost"
elasticsearch.hosts: ["http://localhost:9200"]
elasticsearch.username: "kibana_system"
elasticsearch.password: "your_password"
```

## 3. 로그 수집 설정

### Filebeat 설치 및 구성
```bash
# Filebeat 설치
curl -L -O https://artifacts.elastic.co/downloads/beats/filebeat/filebeat-8.11.0-linux-x86_64.tar.gz
tar xzvf filebeat-8.11.0-linux-x86_64.tar.gz
```

### Filebeat 구성 (filebeat.yml)
```yaml
filebeat.inputs:
- type: filestream
  id: my-logs
  paths:
    - /var/log/*.log
    - /path/to/your/application/*.log

output.elasticsearch:
  hosts: ["localhost:9200"]
  indices:
    - index: "filebeat-%{+yyyy.MM.dd}"
```

## 4. Kibana 대시보드 설정

### 인덱스 패턴 생성
1. Kibana 접속 (http://localhost:5601)
2. Stack Management → Index Patterns → Create index pattern
3. "filebeat-*" 패턴 입력
4. @timestamp 필드를 시간 필드로 설정

### 시각화 생성 예제
1. Discover에서 로그 데이터 확인
2. Visualize Library에서 다양한 차트 생성:
   - 데이터 테이블
   - 막대 그래프
   - 파이 차트
   - 지도 시각화

## 6. 로컬 개발을 위한 최적화

### 리소스 제한 설정
```bash
# Docker 리소스 제한
docker run -d --name elasticsearch \
  -p 9200:9200 -p 9300:9300 \
  -e "discovery.type=single-node" \
  -e "ES_JAVA_OPTS=-Xms512m -Xmx512m" \
  --memory="1g" \
  docker.elastic.co/elasticsearch/elasticsearch:8.11.0
```

### 로그 회전 설정
```bash
# logrotate 설정
/path/to/your/logs/*.log {
    daily
    rotate 7
    compress
    delaycompress
    missingok
    notifempty
    create 644 root root
}
```

## 8. 문제 해결

### 일반적인 문제 및 해결 방법
1. **메모리 부족**: ES_JAVA_OPTS로 힙 크기 조정
2. **디스크 공간 부족**: ILM 정책 설정으로 오래된 데이터 자동 삭제
3. **성능 저하**: 샤드 수 최적화 및 인덱스 템플릿 사용

이렇게 구성하면 로컬 환경에서도 효과적인 로그 분석 시스템을 구축할 수 있습니다. 특정 애플리케이션에 맞게 추가 설정이 필요하시면 말씀해주세요.
