물론입니다. Apache NiFi의 HTTP 빌드 버전에 대해 자세히 설명해 드리겠습니다.

이 질문은 두 가지 주요 맥락에서 해석될 수 있습니다. 두 가지 모두에 대해 설명드리겠습니다.

---

### 1. NiFi 자체의 빌드 버전을 확인하는 HTTP API

Apache NiFi는 자체 상태와 정보를 확인할 수 있는 강력한 RESTful API를 제공합니다. 이 API를 통해 **NiFi가 현재 실행 중인 버전(빌드 버전)**을 정확히 확인할 수 있습니다.

**확인 방법:**

1.  **API Endpoint:** NiFi가 설치된 서버의 다음 API 주소로 HTTP GET 요청을 보냅니다.
    ```
    http://<nifi-server-ip>:<port>/nifi-api/system/about
    ```
    *   기본 포트는 8443(HTTPS) 또는 8080(HTTP)입니다. (설정에 따라 다름)

2.  **응답 결과:** JSON 형식으로 응답이 오며, 여기서 `version` 필드와 `buildTag` 필드를 확인하면 됩니다.
    ```json
    {
      "about": {
        "title": "Apache NiFi",
        "version": "2.0.0", // NiFi의 메이저 버전
        "uri": "https://nifi.apache.org",
        "contentViewerUrl": "/nifi-content-viewer/",
        "timezone": "Asia/Seoul",
        "buildTag": "nifi-2.0.0-RC2", // 상세 빌드 버전 (Tag)
        "buildRevision": "a65ce8228", // Git 커밋 해시
        "buildBranch": "main",
        "buildTimestamp": "2023-11-06T20:57:19Z" // 빌드 시간
      }
    }
    ```

3.  **UI를 통한 확인:**
    *   NiFi 웹 UI (http://<server-ip>:<port>/nifi)에 접속합니다.
    *   화면 우측 상단의 `>` 아이콘을 클릭하여 메뉴를 확장합니다.
    *   **About** 항목을 클릭하면 팝업 창에서 버전 정보를 직관적으로 확인할 수 있습니다.

**결론:** NiFi의 **HTTP API(`/nifi-api/system/about`)**를 호출하거나 UI의 **About** 창을 보면 정확한 빌드 버전을 확인할 수 있습니다. 버전은 `2.0.0`, `1.25.0` 등의 형식이고, 보다 상세한 빌드 정보는 `buildTag` (예: `nifi-2.0.0-RC2`)에서 확인 가능합니다.

### 2. NiFi 빌드에 사용된 HTTP 라이브러리/컴포넌트의 버전

다른 맥락으로, "NiFi를 빌드할 때 사용된 HTTP 클라이언트 또는 서버 라이브러리의 버전이 무엇인가?"라는 질문일 수도 있습니다.

이 경우 답변은 **"NiFi는 내부적으로 여러 HTTP 라이브러리를 사용하며, 그 버전은 NiFi의 버전과 의존성(Dependency)에 따라 달라진다"** 입니다.

NiFi의 핵심 컴포넌트는 다음과 같은 라이브러리들을 사용합니다.

1.  **Jetty:**
    *   **역할:** NiFi의 내장 웹 서버입니다. UI와 REST API를 제공하는 HTTP/HTTPS 서버의 역할을 합니다.
    *   **버전 확인:** NiFi 배포판의 `lib` 디렉토리 내 jar 파일 이름으로 유추할 수 있습니다 (예: `jetty-server-9.4.53.v20231009.jar`).
    *   **주요 버전:** NiFi 1.x 및 2.x 대에서는 주로 **Jetty 9.4.x** 버전을 사용합니다.

2.  **Apache HttpClient:**
    *   **역할:** `InvokeHTTP` 프로세서와 같은 컴포넌트가 외부 서버로 HTTP 요청을 보낼 때 사용하는 클라이언트 라이브러리입니다.
    *   **버전 확인:** 마찬가지로 `lib` 디렉토리에서 jar 파일을 확인하면 됩니다 (예: `httpclient-4.5.14.jar`).
    *   **주요 버전:** NiFi 2.0.0 기준으로 **HttpComponents HttpClient 4.5.x** 버전을 사용합니다.

3.  **JAX-RS (Jersey):**
    *   **역할:** NiFi의 REST API를 구현하는 데 사용되는 프레임워크입니다.
    *   **버전:** Jersey 2.x 버전을 사용합니다.

**정리:**
*   **서버 (Jetty):** 9.4.x
*   **클라이언트 (HttpClient):** 4.5.x

### 최종 요약

*   **"NiFi의 버전을 HTTP로 확인하고 싶다"** → **`http://<server>:port/nifi-api/system/about`** API를 호출하거나 UI의 **About** 창을 확인하세요.
*   **"NiFi를 빌드할 때 사용된 HTTP 라이브러리의 버전이 궁금하다"** → 내장 웹 서버는 **Jetty 9.4.x**, HTTP 클라이언트는 **Apache HttpClient 4.5.x**를 주로 사용합니다. 정확한 버전은 NiFi의 `lib` 디렉토리에서 jar 파일 이름을 확인해야 합니다.
