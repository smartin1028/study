## Feign SSL 오류 해결 방법

Feign Client는 내부적으로 Apache HttpClient나 OkHttp를 사용하며, 이러한 HTTP 클라이언트에서 SSL 인증서 검증 관련 오류가 발생할 수 있습니다.

### 1. 가장 일반적인 SSL 오류 원인

- **자체 서명된 인증서(Self-signed Certificate)** 사용
- **신뢰할 수 없는 CA(인증 기관)**에서 발급된 인증서
- **호스트 이름 불일치** (CN 또는 Subject Alternative Name 불일치)
- **만료된 인증서**

### 2. 해결 방법 (단계별)

#### 방법 1: SSL 검증 비활성화 (개발 환경 전용)

**주의: 이 방법은 보안상 프로덕션 환경에서는 사용하지 마세요.**

```java
import feign.Client;
import feign.okhttp.OkHttpClient;
import okhttp3.OkHttpClient.Builder;
import javax.net.ssl.*;

@Configuration
public class FeignConfig {
    
    @Bean
    public Client feignClient() throws Exception {
        // SSL 컨텍스트 생성 (모든 인증서 신뢰)
        SSLContext sslContext = SSLContext.getInstance("TLS");
        TrustManager[] trustAllCerts = new TrustManager[]{
            new X509TrustManager() {
                public java.security.cert.X509Certificate[] getAcceptedIssuers() {
                    return null;
                }
                public void checkClientTrusted(
                    java.security.cert.X509Certificate[] certs, String authType) {
                }
                public void checkServerTrusted(
                    java.security.cert.X509Certificate[] certs, String authType) {
                }
            }
        };
        
        sslContext.init(null, trustAllCerts, new java.security.SecureRandom());
        
        // OkHttpClient 설정
        okhttp3.OkHttpClient client = new Builder()
            .sslSocketFactory(sslContext.getSocketFactory(), (X509TrustManager)trustAllCerts[0])
            .hostnameVerifier((hostname, session) -> true) // 호스트명 검증 비활성화
            .build();
            
        return new OkHttpClient(client);
    }
}
```

#### 방법 2: 특정 인증서만 신뢰하도록 설정

```java
import java.io.InputStream;
import java.security.KeyStore;
import java.security.cert.CertificateFactory;
import java.security.cert.X509Certificate;

@Configuration
public class FeignConfig {
    
    @Bean
    public Client feignClient() throws Exception {
        // 특정 CA 인증서 로드
        CertificateFactory cf = CertificateFactory.getInstance("X.509");
        InputStream certInputStream = getClass().getResourceAsStream("/your-ca-certificate.crt");
        X509Certificate caCert = (X509Certificate)cf.generateCertificate(certInputStream);
        
        // 키스토어에 인증서 추가
        KeyStore keyStore = KeyStore.getInstance(KeyStore.getDefaultType());
        keyStore.load(null, null);
        keyStore.setCertificateEntry("caCert", caCert);
        
        // TrustManagerFactory 초기화
        TrustManagerFactory tmf = TrustManagerFactory.getInstance(TrustManagerFactory.getDefaultAlgorithm());
        tmf.init(keyStore);
        
        // SSL 컨텍스트 설정
        SSLContext sslContext = SSLContext.getInstance("TLS");
        sslContext.init(null, tmf.getTrustManagers(), null);
        
        okhttp3.OkHttpClient client = new Builder()
            .sslSocketFactory(sslContext.getSocketFactory(), (X509TrustManager)tmf.getTrustManagers()[0])
            .build();
            
        return new OkHttpClient(client);
    }
}
```

#### 방법 3: application.yml/properties를 통한 설정

```yaml
feign:
  client:
    config:
      default:
        loggerLevel: full
        connectTimeout: 5000
        readTimeout: 5000
```

### 3. Feign Interface 예시

```java
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.GetMapping;

@FeignClient(
    name = "exampleClient",
    url = "https://your-api-domain.com",
    configuration = FeignConfig.class // 위에서 만든 Config 클래스
)
public interface ExampleFeignClient {
    
    @GetMapping("/api/data")
    String getData();
}
```

### 5. 프로덕션 환경 권장 사항

1. **적절한 CA 인증서 사용**
2. **SSL 검증을 항상 활성화** 상태로 유지
3. **신뢰할 수 있는 인증 기관**에서 발급받은 인증서 사용
4. **정기적인 인증서 갱신** 관리

### 6. 문제 진단 방법

```java
// SSL 디버깅 활성화 (application.properties)
javax.net.debug=ssl
```

이 설정으로 SSL 핸드셰이크 과정을 상세히 확인할 수 있습니다.
