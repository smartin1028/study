## 2. Basic Auth 인증 상세 설명

### Basic Auth란?
- **HTTP Basic Authentication** 방식
- `username:password`를 Base64로 인코딩하여 헤더에 포함
- 형식: `Authorization: Basic base64(username:password)`

### 인증 헤더 생성 방식
```java
import java.util.Base64;

public class BasicAuthUtil {
    public static String createBasicAuthHeader(String username, String password) {
        String credentials = username + ":" + password;
        return "Basic " + Base64.getEncoder().encodeToString(credentials.getBytes());
    }
}
```

## 3. Feign Client 구현

### Elasticsearch Feign Client 인터페이스
```java
import feign.Headers;
import feign.Param;
import feign.RequestLine;
import feign.Response;

public interface ElasticsearchClient {
    
    // 인덱스 조회
    @RequestLine("GET /{index}/_search")
    @Headers({
        "Content-Type: application/json",
        "Authorization: {authorization}"
    })
    Response search(
        @Param("index") String index,
        @Param("authorization") String authorization,
        String query
    );
    
    // 클러스터 건강 상태 확인
    @RequestLine("GET /_cluster/health")
    @Headers("Authorization: {authorization}")
    Response clusterHealth(@Param("authorization") String authorization);
    
    // 인덱스 정보 조회
    @RequestLine("GET /{index}")
    @Headers("Authorization: {authorization}")
    Response getIndex(@Param("index") String index, @Param("authorization") String authorization);
}
```

### Feign Client Builder
```java
import feign.Feign;
import feign.Logger;
import feign.gson.GsonDecoder;
import feign.gson.GsonEncoder;
import feign.okhttp.OkHttpClient;
import feign.slf4j.Slf4jLogger;

public class ElasticsearchFeignBuilder {
    
    public static ElasticsearchClient build(String elasticsearchUrl, String username, String password) {
        String basicAuth = BasicAuthUtil.createBasicAuthHeader(username, password);
        
        return Feign.builder()
                .client(new OkHttpClient())
                .encoder(new GsonEncoder())
                .decoder(new GsonDecoder())
                .logger(new Slf4jLogger(ElasticsearchClient.class))
                .logLevel(Logger.Level.FULL)
                .target(new ElasticsearchTarget(elasticsearchUrl, basicAuth));
    }
    
    // 동적 인증을 위한 Target 구현
    static class ElasticsearchTarget implements feign.Target<ElasticsearchClient> {
        private final String url;
        private final String authHeader;
        
        public ElasticsearchTarget(String url, String authHeader) {
            this.url = url;
            this.authHeader = authHeader;
        }
        
        @Override
        public Class<ElasticsearchClient> type() {
            return ElasticsearchClient.class;
        }
        
        @Override
        public String name() {
            return "elasticsearch";
        }
        
        @Override
        public String url() {
            return url;
        }
        
        public String getAuthHeader() {
            return authHeader;
        }
    }
}
```

## 4. 사용 예제

### 메인 애플리케이션
```java
import com.google.gson.JsonObject;
import com.google.gson.JsonParser;
import feign.Response;

public class ElasticsearchExample {
    
    public static void main(String[] args) {
        String elasticsearchUrl = "https://your-elasticsearch-host:9200";
        String username = "your-username";
        String password = "your-password";
        
        // Feign Client 생성
        ElasticsearchClient client = ElasticsearchFeignBuilder.build(elasticsearchUrl, username, password);
        
        try {
            // 1. 클러스터 건강 상태 확인
            Response healthResponse = client.clusterHealth(
                BasicAuthUtil.createBasicAuthHeader(username, password)
            );
            System.out.println("Cluster Health: " + healthResponse.status());
            
            // 2. 특정 인덱스 조회
            String indexName = "my-index";
            Response indexResponse = client.getIndex(
                indexName,
                BasicAuthUtil.createBasicAuthHeader(username, password)
            );
            System.out.println("Index Info: " + indexResponse.status());
            
            // 3. 검색 쿼리 실행
            String searchQuery = "{\n" +
                "  \"query\": {\n" +
                "    \"match_all\": {}\n" +
                "  },\n" +
                "  \"size\": 10\n" +
                "}";
            
            Response searchResponse = client.search(
                indexName,
                BasicAuthUtil.createBasicAuthHeader(username, password),
                searchQuery
            );
            
            // 응답 처리
            if (searchResponse.status() == 200) {
                String responseBody = searchResponse.body().toString();
                JsonObject jsonResponse = JsonParser.parseString(responseBody).getAsJsonObject();
                System.out.println("Search Results: " + jsonResponse);
            }
            
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

## 5. 고급 설정: Request Interceptor 사용

### Basic Auth Interceptor 구현
```java
import feign.RequestInterceptor;
import feign.RequestTemplate;

public class BasicAuthRequestInterceptor implements RequestInterceptor {
    private final String authHeader;
    
    public BasicAuthRequestInterceptor(String username, String password) {
        this.authHeader = BasicAuthUtil.createBasicAuthHeader(username, password);
    }
    
    @Override
    public void apply(RequestTemplate template) {
        template.header("Authorization", authHeader);
        template.header("Content-Type", "application/json");
    }
}
```

### Interceptor를 사용한 Feign Client Builder
```java
public class ElasticsearchFeignBuilderWithInterceptor {
    
    public static ElasticsearchClient build(String elasticsearchUrl, String username, String password) {
        return Feign.builder()
                .client(new OkHttpClient())
                .encoder(new GsonEncoder())
                .decoder(new GsonDecoder())
                .logger(new Slf4jLogger(ElasticsearchClient.class))
                .logLevel(Logger.Level.FULL)
                .requestInterceptor(new BasicAuthRequestInterceptor(username, password))
                .target(ElasticsearchClient.class, elasticsearchUrl);
    }
}
```

## 6. SSL/TLS 설정 (필요한 경우)

```java
import okhttp3.OkHttpClient;
import javax.net.ssl.*;
import java.security.cert.CertificateException;
import java.util.concurrent.TimeUnit;

public class SSLUtils {
    
    public static OkHttpClient createUnsafeOkHttpClient() {
        try {
            final TrustManager[] trustAllCerts = new TrustManager[]{
                new X509TrustManager() {
                    @Override
                    public void checkClientTrusted(java.security.cert.X509Certificate[] chain, String authType) 
                            throws CertificateException {}
                    
                    @Override
                    public void checkServerTrusted(java.security.cert.X509Certificate[] chain, String authType) 
                            throws CertificateException {}
                    
                    @Override
                    public java.security.cert.X509Certificate[] getAcceptedIssuers() {
                        return new java.security.cert.X509Certificate[]{};
                    }
                }
            };
            
            final SSLContext sslContext = SSLContext.getInstance("SSL");
            sslContext.init(null, trustAllCerts, new java.security.SecureRandom());
            
            final SSLSocketFactory sslSocketFactory = sslContext.getSocketFactory();
            
            OkHttpClient.Builder builder = new OkHttpClient.Builder();
            builder.sslSocketFactory(sslSocketFactory, (X509TrustManager) trustAllCerts[0]);
            builder.hostnameVerifier((hostname, session) -> true);
            
            builder.connectTimeout(30, TimeUnit.SECONDS);
            builder.readTimeout(30, TimeUnit.SECONDS);
            builder.writeTimeout(30, TimeUnit.SECONDS);
            
            return builder.build();
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }
}
```

## 7. 에러 처리 및 재시도 메커니즘

```java
import feign.Retryer;
import feign.codec.ErrorDecoder;

public class ElasticsearchFeignConfig {
    
    public static ElasticsearchClient buildWithRetry(String url, String username, String password) {
        return Feign.builder()
                .client(new OkHttpClient())
                .encoder(new GsonEncoder())
                .decoder(new GsonDecoder())
                .errorDecoder(new ElasticsearchErrorDecoder())
                .retryer(new Retryer.Default(1000, 8000, 3))
                .requestInterceptor(new BasicAuthRequestInterceptor(username, password))
                .target(ElasticsearchClient.class, url);
    }
    
    static class ElasticsearchErrorDecoder implements ErrorDecoder {
        @Override
        public Exception decode(String methodKey, Response response) {
            // Elasticsearch 특화 에러 처리
            return new RuntimeException("Elasticsearch error: " + response.status());
        }
    }
}
```

## 주요 주의사항

1. **보안**: Basic Auth는 base64 인코딩만 사용하므로 HTTPS를 반드시 사용해야 합니다.
2. **자격 증명 관리**: 코드에 직접 자격 증명을 하드코딩하지 말고, 환경 변수나 보안 저장소를 사용하세요.
3. **연결 시간**: Elasticsearch 클러스터의 응답 시간에 따라 적절한 timeout을 설정하세요.
4. **에러 처리**: Feign의 에러 디코더를 사용하여 Elasticsearch 특화 에러 처리를 구현하세요.

이렇게 구현하면 Feign을 사용하여 Elasticsearch 9.0 버전에 Basic Auth 인증으로 안전하게 접근할 수 있습니다.
