## Docker Compose 파일이란?

**Docker Compose 파일**은 YAML 형식으로 작성된 설정 파일로, **다중 컨테이너 Docker 애플리케이션을 정의하고 실행하기 위한 도구**입니다. 단일 명령어로 여러 컨테이너를 한 번에 생성, 구성 및 실행할 수 있게 해줍니다.

---

## 기본 파일 구조와 형식

### 파일 이름
- 기본 파일명: `docker-compose.yml` 또는 `docker-compose.yaml`
- 다른 이름 사용 시: `-f` 옵션으로 지정 가능

### 버전 지정 (선택사항)
```yaml
version: '3.8'
```
⚠️ 참고: Docker Compose v1.29.0부터는 `version` 필드가 선택사항이 되었습니다.

---

## 주요 구성 요소와 문법

### 1. Services (서비스)
각 컨테이너를 정의하는 부분입니다.

```yaml
services:
  web:
    image: nginx:latest
    ports:
      - "80:80"
    volumes:
      - ./html:/usr/share/nginx/html
  
  database:
    image: postgres:13
    environment:
      POSTGRES_DB: myapp
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
```

### 2. Networks (네트워크)
컨테이너 간 통신을 위한 네트워크를 정의합니다.

```yaml
networks:
  app-network:
    driver: bridge
```

### 3. Volumes (볼륨)
데이터 지속성을 위한 볼륨을 정의합니다.

```yaml
volumes:
  db-data:
```

## 실전 예제: 웹 애플리케이션 + 데이터베이스

```yaml
version: '3.8'

services:
  # 웹 서버
  webapp:
    build: .
    ports:
      - "3000:3000"
    environment:
      - NODE_ENV=production
      - DATABASE_URL=postgresql://user:password@db:5432/mydb
    depends_on:
      - db
    networks:
      - app-network

  # 데이터베이스
  db:
    image: postgres:13
    environment:
      POSTGRES_DB: mydb
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
    volumes:
      - postgres-data:/var/lib/postgresql/data
    networks:
      - app-network

  # 리버스 프록시
  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf
    depends_on:
      - webapp
    networks:
      - app-network

volumes:
  postgres-data:

networks:
  app-network:
    driver: bridge
```

## 주요 명령어

### 애플리케이션 실행
```bash
docker-compose up
```

### 백그라운드 실행
```bash
docker-compose up -d
```

### 서비스 중지
```bash
docker-compose down
```

### 상태 확인
```bash
docker-compose ps
```

### 로그 보기
```bash
docker-compose logs
```

## 활용 시나리오

### 1. 개발 환경
- 로컬에서 전체 애플리케이션 스택 실행
- 핫 리로딩 설정
- 디버깅 포트 노출

### 2. 테스트 환경
- CI/CD 파이프라인에서 테스트 실행
- 일관된 테스트 환경 보장

### 3. 프로덕션 환경 (제한적)
- 단순한 프로덕션 배포
- 작은 규모의 애플리케이션

## 버전 관리 전략

### Docker Compose 파일 버전별 특징
- **v1**: 초기 버전 (현재 거의 사용되지 않음)
- **v2**: 네트워크/볼륨 지원 강화
- **v3**: Docker Swarm과의 호환성 강화
- **최신**: 버전 필드 생략 가능, 최신 기능 지원

---

## 모범 사례

1. **환경 변수 사용**: `.env` 파일로 민감정보 관리
2. **의존성 관리**: `depends_on`으로 서비스 시작 순서 제어
3. **리소스 제한**: CPU, 메모리 제한 설정
4. **헬스체크**: 서비스 건강 상태 모니터링
5. **볼륨 활용**: 데이터 지속성 보장

## 확장 기능

### 다중 Compose 파일
```bash
# 기본 + 오버라이드 조합
docker-compose -f docker-compose.yml -f docker-compose.prod.yml up
```

### 환경별 설정
- `docker-compose.dev.yml` (개발용)
- `docker-compose.test.yml` (테스트용)
- `docker-compose.prod.yml` (프로덕션용)

Docker Compose는 개발자에게 **로컬 개발 환경 구축의 복잡성을 크게 줄여주는** 강력한 도구입니다. 마이크로서비스 아키텍처나 멀티티어 애플리케이션 개발 시 특히 유용합니다.
