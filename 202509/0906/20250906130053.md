
# n8n을 이용한 텔레그램 메시지 수신 및 AI 분석 워크플로우 구축

n8n에서 텔레그램 메시지를 수신하고 AI로 분석한 후 결과를 파일로 저장하여 전송하는 워크플로우를 구성하는 방법을 상세히 설명드리겠습니다.

## 필요한 노드 및 설정

이 워크플로우를 구현하기 위해 다음 노드들이 필요합니다:
1. Telegram Trigger 노드 - 메시지 수신
2. Code 노드 또는 Function 노드 - 데이터 전처리
3. AI 서비스 노드 (OpenAI, Hugging Face 등) - 메시지 분석
4. Code 노드 - 결과 가공 및 파일 생성
5. Telegram 노드 - 결과 전송

## 단계별 구현 방법

### 1. Telegram Trigger 노드 설정

먼저 Telegram 봇을 생성하고 토큰을 얻어야 합니다:

1. Telegram에서 @BotFather를 찾아 대화 시작
2. `/newbot` 명령어로 새 봇 생성
3. 봇 이름과 사용자 이름 설정
4. 제공된 API 토큰을 복사

n8n에서 Telegram Trigger 노드를 추가하고:
- Authentication: 선택한 방법 (API Token 권장)
- Credentials: 새로 생성하여 API Token 입력
- Event Type: Message
- Additional Fields: 필요한 경우 추가 옵션 설정

### 2. 데이터 전처리 노드 설정

Code 노드를 추가하여 수신된 메시지를 AI 분석에 적합한 형식으로 가공합니다:

```javascript
// 메시지 데이터 추출 및 정제
const message = $input.first().json.message;
const text = message.text;
const chatId = message.chat.id;
const userId = message.from.id;

// 분석을 위한 데이터 구조화
const analysisData = {
  text: text,
  metadata: {
    chatId: chatId,
    userId: userId,
    timestamp: new Date().toISOString()
  }
};

return [{
  json: analysisData,
  pairedItem: $input.item
}];
```

### 3. AI 분석 노드 설정

OpenAI나 Hugging Face 등의 AI 서비스 노드를 추가합니다:

**OpenAI 노드 구성:**
- Authentication: OpenAI API 키 설정
- Resource: Completions
- Operation: Create
- Model: gpt-3.5-turbo 또는 원하는 모델 선택
- Prompt: 전처리된 메시지 텍스트 포함

```javascript
// 시스템 프롬프트 설정 (Function 노드에서)
const systemPrompt = "다음 메시지를 분석하고 요약해주세요. 주요 주제, 감정, 필요한 조치 항목을 식별하세요.";

return [{
  json: {
    messages: [
      { role: "system", content: systemPrompt },
      { role: "user", content: $input.first().json.text }
    ],
    max_tokens: 500,
    temperature: 0.7
  },
  pairedItem: $input.item
}];
```

### 4. 결과 처리 및 파일 생성 노드

AI 분석 결과를 가공하고 파일로 저장합니다:

```javascript
// AI 응답 파싱
const aiResponse = $input.first().json.choices[0].message.content;
const originalMessage = $('전처리 노드').first().json.text;

// 결과 구조화
const analysisResult = {
  originalMessage: originalMessage,
  analysis: aiResponse,
  analyzedAt: new Date().toISOString(),
  chatId: $('전처리 노드').first().json.metadata.chatId
};

// 파일 생성 (텍스트 또는 JSON)
const fileName = `analysis_${Date.now()}.txt`;
const fileContent = `
메시지 분석 결과
=================
원본 메시지: ${originalMessage}

분석 결과:
${aiResponse}

생성 시간: ${new Date().toLocaleString('ko-KR')}
`;

return [{
  json: analysisResult,
  binary: {
    data: await this.helpers.toBinary(Buffer.from(fileContent).toString('base64')),
    fileName: fileName,
    mimeType: 'text/plain'
  },
  pairedItem: $input.item
}];
```

### 5. 파일 전송 노드 설정

Telegram 노드를 추가하여 분석 결과를 파일로 전송합니다:

- Authentication: 이전과 동일한 Telegram 자격증명 사용
- Resource: Message
- Operation: Send Document
- Chat ID: `{{ $json.metadata.chatId }}` (전처리 노드에서 가져온 값)
- File: Binary Data 선택 및 이전 노드의 binary 데이터 매핑
- Caption: "메시지 분석 결과입니다."

## 완성된 워크플로우 구조

```
Telegram Trigger → Data Preprocessing → AI Analysis → Result Processing → Telegram Send Document
```

## 고급 설정 및 최적화

1. **에러 처리**: Error Trigger 노드를 추가하여 워크플로우 실패 시 알림 설정
2. **속도 제한**: Rate Limit 노드로 API 호출 제한避免
3. **로그ging**: 메시지 분석 기록을 데이터베이스에 저장하는 노드 추가
4. **다중 형식 지원**: 분석 결과를 PDF, HTML 등 다양한 형식으로 생성 가능

## 주의사항

1. Telegram 봇의 Privacy 모드 설정 확인 - 그룹 채팅에서 메시지 수신을 위해 비공개 모드 해제 필요
2. AI 서비스의 사용량 및 비용 모니터링
3. 데이터 프라이버시 보호 - 개인정보가 포함된 메시지 처리에 유의

이렇게 구성된 워크플로우는 텔레그램으로 수신된 메시지를 AI로 분석하고, 결과를 정리하여 파일 형태로 사용자에게 다시 전송해 줍니다. 필요에 따라 분석 내용이나 파일 형식을 customize할 수 있습니다.
