# Oracle Client 설치 확인 방법

Oracle Client 설치 여부를 확인하는 방법에 대해 상세히 설명해 드리겠습니다.

## Windows 환경에서 확인 방법

### 1. 레지스트리 확인
```
HKEY_LOCAL_MACHINE\SOFTWARE\ORACLE
```
- 레지스트리 편집기에서 위 경로 확인
- Oracle 관련 키가 존재하면 설치됨

### 2. 파일 시스템 확인
```
C:\app\client\[사용자명]\product\[버전]\client_[번호]
```
또는
```
C:\Oracle\product\[버전]\client_[번호]
```

### 3. 환경 변수 확인
- PATH 변수에 Oracle 경로가 포함되어 있는지 확인
- ORACLE_HOME 변수 존재 여부 확인

### 4. 명령 프롬프트에서 확인
```cmd
sqlplus /nolog
```
- SQL*Plus 실행 가능 여부로 확인

```cmd
tnsping [DB 서비스명]
```
- 네트워크 연결 테스트

## Linux/Unix 환경에서 확인 방법

### 1. 환경 변수 확인
```bash
echo $ORACLE_HOME
echo $PATH | grep oracle
echo $LD_LIBRARY_PATH | grep oracle
```

### 2. 설치 디렉토리 확인
```bash
find / -name "sqlplus" -type f 2>/dev/null
find / -name "libclntsh*" -type f 2>/dev/null
```

### 3. 패키지 관리자로 확인 (Linux)
```bash
# RPM 기반 시스템
rpm -qa | grep -i oracle

# Debian 기반 시스템
dpkg -l | grep -i oracle
```

### 4. 실행 파일 확인
```bash
which sqlplus
which tnsping
```

## 공통 확인 사항

### 버전 확인
```bash
sqlplus -v
```

### 라이브러리 확인
```bash
# Windows
dir %ORACLE_HOME%\bin\oci.dll

# Linux
ls $ORACLE_HOME/lib/libclntsh*
```

## 설치되지 않은 경우 나타나는 증상

1. `sqlplus: command not found` 오류
2. OCI 관련 연결 오류 발생
3. Oracle 관련 환경 변수가 설정되지 않음

## 자동 확인 스크립트 예제 (Windows 배치 파일)
```batch
@echo off
if defined ORACLE_HOME (
    echo Oracle Home: %ORACLE_HOME%
    if exist "%ORACLE_HOME%\bin\sqlplus.exe" (
        echo SQL*Plus is installed
        "%ORACLE_HOME%\bin\sqlplus.exe" -v
    ) else (
        echo SQL*Plus not found
    )
) else (
    echo ORACLE_HOME is not set
)
```

이러한 방법들을 통해 Oracle Client의 설치 여부와 버전, 정상 동작 여부를 확인할 수 있습니다.
