Maven에서 `maven install`을 실행할 때 **`resources` 디렉토리의 파일은 기본적으로 빌드 결과물에 포함됩니다**. 다만, 특정 조건이나 설정에 따라 포함되지 않을 수 있으니 아래 내용을 참고하세요.

---

### 1. **기본 동작: `resources` 디렉토리의 파일 포함**
- Maven은 **`src/main/resources`** 디렉토리의 모든 파일을 **`target/classes`** (또는 빌드 출력 디렉토리)로 복사합니다.
- `maven install` 시 이 파일들은 최종 `.jar`/`.war` 파일에 패키징되어 설치됩니다.
- 예시 구조:
  ```
  my-project/
  ├── src/
  │   ├── main/
  │   │   ├── java/       # Java 소스 코드
  │   │   ├── resources/  # 리소스 파일 (예: .xml, .properties)
  │   │   └── webapp/     # 웹 애플리케이션 리소스 (WAR 프로젝트)
  ├── target/
  │   ├── classes/        # resources 파일이 여기로 복사됨
  │   └── my-project.jar  # 최종 JAR (resources 포함)
  ```

---

### 2. **`resources`가 포함되지 않는 경우**
#### (1) **`<resources>` 설정 오버라이드**
- `pom.xml`에서 `<resources>`를 직접 정의했지만, `<includes>`/`<excludes>`로 필터링한 경우:
  ```xml
  <build>
    <resources>
      <resource>
        <directory>src/main/resources</directory>
        <excludes>
          <exclude>**/*.txt</exclude>  # 모든 .txt 파일 제외
        </excludes>
      </resource>
    </resources>
  </build>
  ```

#### (2) **파일 이름/위치 문제**
- `src/main/resources`가 아닌 다른 경로에 파일을 넣은 경우 (예: `src/test/resources`는 테스트용).
- 파일 이름에 오타가 있거나, 필터링 패턴과 일치하지 않는 경우.

#### (3) **Clean 작업 누락**
- 이전 빌드 결과(`target/`)가 남아있어 변경사항이 반영되지 않을 수 있습니다.  
  **해결법**: `mvn clean install`로 깨끗하게 재빌드.

#### (4) **프로파일 또는 활성화 조건**
- 특정 프로파일에서만 리소스를 포함하도록 설정된 경우:
  ```xml
  <profiles>
    <profile>
      <id>prod</id>
      <build>
        <resources>...</resources>
      </build>
    </profile>
  </profiles>
  ```

---

### 3. **확인 방법**
#### (1) **`target/classes` 디렉토리 확인**
- 빌드 후 `target/classes`를 열어 리소스 파일 존재 여부를 확인합니다.

#### (2) **빌드 출력 로그 분석**
- `mvn install` 실행 시 로그에서 `resources:resources` 단계를 확인:
  ```
  [INFO] Copying 3 resources from src/main/resources to target/classes
  ```

#### (3) **생성된 JAR/WAR 파일 검사**
- `jar tf target/my-project.jar` 명령어로 JAR 내부 파일 목록을 확인합니다.

---

### 4. **의도적으로 리소스 제외하기**
리소스를 빌드에서 제외하려면 `pom.xml`에 명시적으로 설정합니다:
```xml
<build>
  <resources>
    <resource>
      <directory>src/main/resources</directory>
      <excludes>
        <exclude>**/secrets.properties</exclude>
      </excludes>
    </resource>
  </resources>
</build>
```

---

### 요약
- **기본적으로 `src/main/resources`의 파일은 `mvn install` 시 포함됩니다.**
- 포함되지 않는다면 `pom.xml` 설정, 파일 경로, 빌드 환경을 점검하세요.
- `target/classes`와 생성된 JAR 파일을 직접 확인하는 것이 가장 확실한 방법입니다.
