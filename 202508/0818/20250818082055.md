# Spring Boot에서 VO 객체에 프로퍼티 값 설정 방법

Spring Boot에서 VO(Value Object) 객체에 프로퍼티 값을 설정하는 방법은 여러 가지가 있습니다. 아래에 주요 방법들을 상세히 설명드리겠습니다.

## 1. 생성자를 통한 값 설정

가장 기본적인 방법으로 생성자를 이용해 값을 설정할 수 있습니다.

```java
public class UserVO {
    private String name;
    private int age;
    
    // 생성자
    public UserVO(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    // getter, setter 생략
}

// 사용 예시
UserVO user = new UserVO("홍길동", 30);
```

## 2. Setter 메서드를 통한 값 설정

Java Beans 규약에 따라 setter 메서드를 사용하는 방법입니다.

```java
public class UserVO {
    private String name;
    private int age;
    
    // setter 메서드
    public void setName(String name) {
        this.name = name;
    }
    
    public void setAge(int age) {
        this.age = age;
    }
    
    // getter 생략
}

// 사용 예시
UserVO user = new UserVO();
user.setName("홍길동");
user.setAge(30);
```

## 3. Builder 패턴 사용

Lombok 라이브러리의 `@Builder` 어노테이션을 사용하면 편리합니다.

```java
import lombok.Builder;
import lombok.Getter;

@Getter
@Builder
public class UserVO {
    private String name;
    private int age;
}

// 사용 예시
UserVO user = UserVO.builder()
                  .name("홍길동")
                  .age(30)
                  .build();
```

## 4. MapStruct 또는 ModelMapper 사용

객체 간 매핑 라이브러리를 사용하는 방법입니다.

```java
// MapStruct 예시
@Mapper
public interface UserMapper {
    UserMapper INSTANCE = Mappers.getMapper(UserMapper.class);
    
    UserVO toUserVO(UserDTO userDTO);
}

// 사용 예시
UserVO user = UserMapper.INSTANCE.toUserVO(userDTO);
```

## 5. Spring의 @Value 어노테이션 사용

application.properties 또는 application.yml에 정의된 값을 주입할 때 사용합니다.

```java
@Component
public class AppProperties {
    @Value("${app.name}")
    private String name;
    
    @Value("${app.version}")
    private String version;
    
    // getter 생략
}
```

## 6. Jackson을 이용한 JSON 바인딩

REST API에서 JSON 요청을 VO 객체로 변환할 때 사용합니다.

```java
@RestController
public class UserController {
    @PostMapping("/users")
    public ResponseEntity<UserVO> createUser(@RequestBody UserVO userVO) {
        // userVO에 JSON 데이터가 자동 바인딩됨
        return ResponseEntity.ok(userVO);
    }
}
```

## 7. Command 객체로 폼 데이터 바인딩

웹 폼에서 전송된 데이터를 VO 객체로 바인딩합니다.

```java
@Controller
public class UserController {
    @PostMapping("/users")
    public String createUser(UserVO userVO) {
        // 폼 데이터가 userVO에 자동 바인딩됨
        return "redirect:/users";
    }
}
```

## 선택 가이드

- **간단한 객체 생성**: 생성자 또는 setter 사용
- **복잡한 객체 생성**: Builder 패턴 사용
- **외부 설정 값 주입**: @Value 사용
- **DTO <-> VO 변환**: MapStruct 또는 ModelMapper 사용
- **REST API**: Jackson 자동 바인딩
- **폼 데이터**: Spring의 command 객체 바인딩

각 방법은 상황에 따라 적절히 선택하여 사용하시면 됩니다.
