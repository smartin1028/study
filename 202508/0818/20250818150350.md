# PowerShell을 이용한 화면 자동 잠금 방지 스크립트

PowerShell을 사용하여 화면이 자동으로 잠기지 않도록 하는 스크립트를 작성할 수 있습니다. 아래는 마우스를 약간 움직이는 방법과 다른 대체 방법을 포함한 스크립트입니다.

## 방법 1: 마우스 움직임으로 화면 잠금 방지

```powershell
# 화면 잠금 방지 마우스 이동 스크립트
param (
    [int]$minutes = 60,  # 기본 실행 시간(분)
    [int]$interval = 60, # 마우스 이동 간격(초)
    [int]$pixels = 1    # 이동할 픽셀 수
)

Add-Type -AssemblyName System.Windows.Forms

Write-Host "화면 잠금 방지 스크립트 시작 (종료하려면 Ctrl+C를 누르세요)"
Write-Host "$minutes 분 동안 $interval 초 간격으로 마우스를 $pixels 픽셀 이동합니다."

$startTime = Get-Date
$endTime = $startTime.AddMinutes($minutes)

while ((Get-Date) -lt $endTime) {
    $pos = [System.Windows.Forms.Cursor]::Position
    [System.Windows.Forms.Cursor]::Position = New-Object System.Drawing.Point(($pos.X + $pixels), $pos.Y)
    Start-Sleep -Milliseconds 500
    [System.Windows.Forms.Cursor]::Position = New-Object System.Drawing.Point(($pos.X - $pixels), $pos.Y)
    
    $remaining = ($endTime - (Get-Date)).TotalMinutes
    Write-Host "실행 중... 남은 시간: $([math]::Round($remaining, 1)) 분" -NoNewline
    Write-Host "`r" -NoNewline
    
    Start-Sleep -Seconds ($interval - 1)
}

Write-Host "`n스크립트가 완료되었습니다."
```

## 방법 2: 키보드 입력 시뮬레이션 (대체 방법)

```powershell
# 화면 잠금 방지 키보드 입력 스크립트
param (
    [int]$minutes = 60,  # 기본 실행 시간(분)
    [int]$interval = 60  # 키 입력 간격(초)
)

Add-Type -TypeDefinition '
using System;
using System.Runtime.InteropServices;

public class KeyboardInput {
    [DllImport("user32.dll")]
    public static extern void keybd_event(byte bVk, byte bScan, uint dwFlags, UIntPtr dwExtraInfo);
}

public class MouseInput {
    [DllImport("user32.dll")]
    public static extern void mouse_event(uint dwFlags, uint dx, uint dy, uint dwData, UIntPtr dwExtraInfo);
}
'

Write-Host "화면 잠금 방지 스크립트 시작 (종료하려면 Ctrl+C를 누르세요)"
Write-Host "$minutes 분 동안 $interval 초 간격으로 NumLock 상태를 토글합니다."

$startTime = Get-Date
$endTime = $startTime.AddMinutes($minutes)

while ((Get-Date) -lt $endTime) {
    # NumLock 키 토글
    [KeyboardInput]::keybd_event(0x90, 0x45, 0x1, [UIntPtr]::Zero)  # NumLock down
    [KeyboardInput]::keybd_event(0x90, 0x45, 0x2, [UIntPtr]::Zero)  # NumLock up
    
    $remaining = ($endTime - (Get-Date)).TotalMinutes
    Write-Host "실행 중... 남은 시간: $([math]::Round($remaining, 1)) 분" -NoNewline
    Write-Host "`r" -NoNewline
    
    Start-Sleep -Seconds $interval
}

Write-Host "`n스크립트가 완료되었습니다."
```

## 방법 3: 절전 모드 방지 (가장 효과적인 방법)

```powershell
# 절전 모드 및 화면 잠금 방지 스크립트
param (
    [int]$minutes = 60  # 기본 실행 시간(분)
)

# 절전 모드 방지 설정
powercfg -change -monitor-timeout-ac 0
powercfg -change -standby-timeout-ac 0
powercfg -change -hibernate-timeout-ac 0

Write-Host "$minutes 분 동안 절전 모드와 화면 잠금이 방지됩니다. (종료하려면 Ctrl+C를 누르세요)"

$startTime = Get-Date
$endTime = $startTime.AddMinutes($minutes)

try {
    while ((Get-Date) -lt $endTime) {
        $remaining = ($endTime - (Get-Date)).TotalMinutes
        Write-Host "실행 중... 남은 시간: $([math]::Round($remaining, 1)) 분" -NoNewline
        Write-Host "`r" -NoNewline
        Start-Sleep -Seconds 10
    }
}
finally {
    # 원래 설정으로 복원
    powercfg -change -monitor-timeout-ac 10
    powercfg -change -standby-timeout-ac 30
    powercfg -change -hibernate-timeout-ac 0
    Write-Host "`n원래 전원 설정으로 복원되었습니다."
}
```

## 사용 방법

1. 원하는 스크립트를 메모장에 복사하여 `.ps1` 확장자로 저장합니다 (예: `prevent_lock.ps1`)
2. PowerShell을 관리자 권한으로 실행합니다
3. 스크립트를 실행합니다: `.\prevent_lock.ps1 -minutes 120` (120분 동안 실행)

## 주의 사항

- 관리자 권한이 필요한 스크립트가 있습니다
- 회사 정책이나 보안 규정을 위반하지 않는지 확인하세요
- 스크립트 실행 중에는 Ctrl+C로 중지할 수 있습니다
- 방법 3은 가장 효과적이지만 시스템 전원 설정을 변경하므로 주의가 필요합니다

원하는 동작에 따라 적절한 스크립트를 선택하시면 됩니다.
