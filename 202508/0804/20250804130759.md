# Pandas Join 및 정렬 방법 상세 설명

## 1. Join (병합) 방법

Pandas에서는 여러 가지 방법으로 데이터프레임을 병합할 수 있습니다. 주요 메서드는 다음과 같습니다.

### 1.1 merge() 함수

```python
pd.merge(left, right, how='inner', on=None, left_on=None, right_on=None)
```

- **매개변수**:
  - `left`: 왼쪽 데이터프레임
  - `right`: 오른쪽 데이터프레임
  - `how`: 병합 방식 ('inner', 'outer', 'left', 'right')
  - `on`: 조인할 컬럼명 (양쪽 데이터프레임에 동일한 이름일 때)
  - `left_on`/`right_on`: 각 데이터프레임의 조인 컬럼 지정

- **예시**:
```python
import pandas as pd

df1 = pd.DataFrame({'key': ['A', 'B', 'C'], 'value': [1, 2, 3]})
df2 = pd.DataFrame({'key': ['B', 'C', 'D'], 'value': [4, 5, 6]})

# 내부 조인 (교집합)
inner_join = pd.merge(df1, df2, on='key', how='inner')

# 외부 조인 (합집합)
outer_join = pd.merge(df1, df2, on='key', how='outer')

# 왼쪽 조인
left_join = pd.merge(df1, df2, on='key', how='left')

# 오른쪽 조인
right_join = pd.merge(df1, df2, on='key', how='right')
```

### 1.2 join() 메서드

```python
DataFrame.join(other, on=None, how='left', lsuffix='', rsuffix='')
```

- 인덱스를 기준으로 조인 수행
- `merge()`보다 간단하지만 기능이 제한적

```python
df1.set_index('key').join(df2.set_index('key'), how='inner')
```

### 1.3 concat() 함수

```python
pd.concat(objs, axis=0, join='outer', ignore_index=False)
```

- 데이터프레임을 단순히 연결할 때 사용
- `axis=0`은 행 방향(위아래), `axis=1`은 열 방향(좌우) 연결

```python
combined = pd.concat([df1, df2], axis=0)  # 행 방향 연결
combined = pd.concat([df1, df2], axis=1)  # 열 방향 연결
```

## 2. 정렬 방법

### 2.1 sort_values() - 값 기준 정렬

```python
DataFrame.sort_values(by, axis=0, ascending=True, inplace=False)
```

- **매개변수**:
  - `by`: 정렬 기준 컬럼명 (리스트로 여러 컬럼 지정 가능)
  - `ascending`: 오름차순(True) 또는 내림차순(False)
  - `inplace`: 원본 데이터 변경 여부

- **예시**:
```python
df = pd.DataFrame({
    'A': [2, 1, 3],
    'B': ['b', 'a', 'c']
})

# 단일 컬럼 정렬
df.sort_values('A')  # A 컬럼 오름차순
df.sort_values('A', ascending=False)  # A 컬럼 내림차순

# 다중 컬럼 정렬
df.sort_values(['A', 'B'])  # A로 먼저 정렬, 동일값은 B로 정렬
```

### 2.2 sort_index() - 인덱스 기준 정렬

```python
DataFrame.sort_index(axis=0, ascending=True, inplace=False)
```

- 인덱스(행 라벨) 또는 컬럼명(열 라벨) 기준 정렬

```python
df.sort_index()  # 인덱스 오름차순 정렬
df.sort_index(axis=1)  # 컬럼명 알파벳 순 정렬
```

### 2.3 nlargest() / nsmallest() - 상위 N개 추출

```python
DataFrame.nlargest(n, columns)
DataFrame.nsmallest(n, columns)
```

```python
df.nlargest(2, 'A')  # A 컬럼 값이 가장 큰 상위 2개 행
df.nsmallest(1, 'B')  # B 컬럼 값이 가장 작은 행 1개
```

## 3. Join + 정렬 조합 예제

```python
# 두 데이터프레임 조인 후 정렬
merged = pd.merge(df1, df2, on='key', how='outer')
sorted_result = merged.sort_values(['value_x', 'value_y'], ascending=[True, False])
```
