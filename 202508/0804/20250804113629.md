# 엘라스틱서치 결과를 Pandas로 변환하는 방법

엘라스틱서치 검색 결과를 Pandas DataFrame으로 변환하면 데이터 분석과 시각화가 훨씬 편리해집니다. 다음은 여러 가지 방법을 상세히 설명드리겠습니다.

## 1. 기본적인 방법: `elasticsearch` 라이브러리 사용

```python
from elasticsearch import Elasticsearch
import pandas as pd

# Elasticsearch 연결 설정
es = Elasticsearch(["http://localhost:9200"])

# 검색 쿼리 실행
query = {
    "query": {
        "match_all": {}
    },
    "size": 10000  # 가져올 문서 수 (기본값 10)
}

index_name = "your_index_name"
response = es.search(index=index_name, body=query)

# 결과를 Pandas DataFrame으로 변환
hits = response['hits']['hits']
data = [hit['_source'] for hit in hits]
df = pd.DataFrame(data)

# _id 같은 메타데이터도 포함하려면
df_with_meta = pd.DataFrame([
    {**hit['_source'], '_id': hit['_id'], '_score': hit['_score']} 
    for hit in hits
])
```

## 2. `elasticsearch-dsl` 라이브러리 사용 (추천)

```python
from elasticsearch_dsl import Search, connections
import pandas as pd

# 연결 설정
connections.create_connection(hosts=['localhost'])

# 검색 쿼리 생성
s = Search(index='your_index_name').query("match_all")[:10000]
response = s.execute()

# 결과를 DataFrame으로 변환
df = pd.DataFrame([hit.to_dict() for hit in response])
```

## 3. Scroll API 사용 (대량 데이터 처리)

```python
from elasticsearch import Elasticsearch
import pandas as pd

es = Elasticsearch(["http://localhost:9200"])

# 초기 검색 요청
query = {"query": {"match_all": {}}}
response = es.search(
    index="your_index_name",
    scroll='2m',  # 스크롤 컨텍스트 유지 시간
    size=1000,    # 한 번에 가져올 문서 수
    body=query
)

# 첫 번째 배치 처리
scroll_id = response['_scroll_id']
hits = response['hits']['hits']
data = [hit['_source'] for hit in hits]

# 스크롤로 모든 문서 가져오기
while len(hits):
    response = es.scroll(scroll_id=scroll_id, scroll='2m')
    hits = response['hits']['hits']
    data.extend([hit['_source'] for hit in hits])
    scroll_id = response['_scroll_id']

# DataFrame 생성
df = pd.DataFrame(data)
```

## 4. Pandas로 추가 처리하기

DataFrame으로 변환한 후에는 Pandas의 강력한 기능을 활용할 수 있습니다.

```python
# 기본 정보 확인
print(df.info())
print(df.describe())

# 특정 컬럼 선택
df[['field1', 'field2']]

# 필터링
filtered_df = df[df['price'] > 100]

# 그룹화
grouped = df.groupby('category').agg({'price': ['mean', 'count']})

# 시각화

```
