# 자바 21 기본 문법

자바 21은 2023년 9월에 출시된 LTS(Long-Term Support) 버전으로, 여러 가지 새로운 기능과 개선 사항을 도입했습니다. 아래에서 자바의 기본 문법과 자바 21의 주요 새로운 기능을 설명드리겠습니다.

## 기본 문법 구조

// 클래스 정의

## 자바 21의 주요 새로운 기능

### 1. 가상 스레드 (Virtual Threads)

```java
import java.util.concurrent.Executors;

public class VirtualThreadExample {
    public static void main(String[] args) {
        // 가상 스레드 생성
        Thread virtualThread = Thread.ofVirtual()
            .name("virtual-thread")
            .start(() -> {
                System.out.println("Hello from virtual thread!");
            });
        
        try {
            virtualThread.join();
        } catch (InterruptedException e) {
            e.printStackTrace();
        }
        
        // ExecutorService와 함께 사용
        try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
            executor.submit(() -> {
                System.out.println("Task running in virtual thread");
            });
        }
    }
}
```

### 2. 패턴 매칭 (Pattern Matching)

```java
// instanceof 패턴 매칭
Object obj = "Hello Java 21";

// 자바 21 이전
if (obj instanceof String) {
    String s = (String) obj;
    System.out.println(s.length());
}

// 자바 21 이후
if (obj instanceof String s) {
    System.out.println(s.length()); // 자동 캐스팅
}

// switch 표현식에서의 패턴 매칭
String result = switch (obj) {
    case Integer i -> "Integer: " + i;
    case String s when s.length() > 5 -> "Long string: " + s;
    case String s -> "String: " + s;
    case null -> "Null object";
    default -> "Unknown type";
};
```

### 3. Record 패턴 (Record Patterns)

```java
// Record 클래스 정의
record Point(int x, int y) {}

record Circle(Point center, double radius) {}

public class RecordPatternExample {
    public static void main(String[] args) {
        Circle circle = new Circle(new Point(10, 20), 5.0);
        
        // Record 패턴 매칭
        if (circle instanceof Circle(Point(int x, int y), double radius)) {
            System.out.printf("Center: (%d, %d), Radius: %.1f%n", x, y, radius);
        }
    }
}
```

### 5. Sequenced Collections

```java
import java.util.*;

public class SequencedCollectionsExample {
    public static void main(String[] args) {
        // SequencedCollection 인터페이스
        SequencedCollection<String> list = new ArrayList<>();
        list.add("First");
        list.add("Second");
        list.add("Third");
        
        System.out.println("First element: " + list.getFirst());
        System.out.println("Last element: " + list.getLast());

}
```

## 기본 제어 구조

```java
public class ControlStructures {
    public static void main(String[] args) {
        int number = 10;
        
        // if-else 문
        if (number > 0) {
            System.out.println("Positive");
        } else if (number < 0) {
            System.out.println("Negative");
        } else {
            System.out.println("Zero");
        }
        
        // switch 표현식 (자바 14+)
        String size = switch (number) {
            case 1, 2, 3 -> "Small";
            case 4, 5, 6 -> "Medium";
            case 7, 8, 9 -> "Large";
            default -> "Unknown";
        };
        
        // for-each 루프
        int[] numbers = {1, 2, 3, 4, 5};
        for (int n : numbers) {
            System.out.println(n);
        }
        
        // while 루프
        int i = 0;
        while (i < 5) {
            System.out.println(i);
            i++;
        }
    }
}
```

## 메서드 정의

```java
public class MethodExamples {
    
    // 기본 메서드
    public static int add(int a, int b) {
        return a + b;
    }
    
    // 가변인자 메서드
    public static int sum(int... numbers) {
        int total = 0;
        for (int num : numbers) {
            total += num;
        }
        return total;
    }
    
    public static void main(String[] args) {
        System.out.println(add(5, 3));          // 8
        System.out.println(sum(1, 2, 3, 4, 5)); // 15
    }
}
```

## 클래스와 객체

```java
// 클래스 정의
class Person {
    // 필드
    private String name;
    private int age;
    
    // 생성자
    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    // 메서드
    public void introduce() {
        System.out.println("Hello, I'm " + name + " and I'm " + age + " years old.");
    }
    
    // Getter/Setter
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
}

public class ClassExample {
    public static void main(String[] args) {
        // 객체 생성
        Person person = new Person("John", 30);
        person.introduce();
    }
}
```
