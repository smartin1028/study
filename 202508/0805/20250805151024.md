# Spring JPA와 JdbcTemplate 함께 사용 가능 여부

네, Spring JPA와 JdbcTemplate을 함께 사용하는 것이 가능하며 실제로 많은 프로젝트에서 이 조합을 사용합니다. 각 기술의 특징과 함께 사용하는 방법을 설명드리겠습니다.

## 함께 사용 가능한 이유

1. **호환성**: Spring Framework는 모듈화되어 있어 JPA와 JDBC를 동시에 지원
2. **트랜잭션 관리**: Spring의 `@Transactional`이 두 기술을 동일 트랜잭션으로 관리 가능
3. **유연성**: 각 기술의 장점을 상황에 따라 활용 가능

## 일반적인 사용 시나리오

### JPA를 주로 사용하는 경우
- **CRUD 작업**: JPA Repository 사용
- **복잡한 쿼리**: JdbcTemplate으로 네이티브 SQL 실행
- **대량 데이터 처리**: JdbcTemplate의 batchUpdate() 사용

### JdbcTemplate을 주로 사용하는 경우
- **간단한 도메인 객체 매핑**: JPA로 기본적인 엔티티 관리
- **객체-관계 매핑**: JPA의 편리한 ORM 기능 활용

## 구현 방법

### 1. 의존성 추가 (Gradle 예시)
```groovy
implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
implementation 'org.springframework.boot:spring-boot-starter-jdbc'
```

### 2. 구성 클래스 예시
```java
@Configuration
public class DatabaseConfig {
    
    @Bean
    public JdbcTemplate jdbcTemplate(DataSource dataSource) {
        return new JdbcTemplate(dataSource);
    }
}
```

### 3. 함께 사용하는 서비스 예시
```java
@Service
@Transactional
public class UserService {
    
    private final UserRepository userRepository; // JPA Repository
    private final JdbcTemplate jdbcTemplate;
    
    public UserService(UserRepository userRepository, JdbcTemplate jdbcTemplate) {
        this.userRepository = userRepository;
        this.jdbcTemplate = jdbcTemplate;
    }
    
    // JPA 사용 메서드
    public User findById(Long id) {
        return userRepository.findById(id).orElseThrow();
    }
    
    // JdbcTemplate 사용 메서드
    public List<User> findUsersWithComplexQuery() {
        String sql = "SELECT * FROM users WHERE status = ? AND created_at > ?";
        return jdbcTemplate.query(sql, 
            (rs, rowNum) -> new User(
                rs.getLong("id"),
                rs.getString("name")
            ),
            "ACTIVE", 
            LocalDate.now().minusMonths(1)
        );
    }
}
```

## 주의사항

1. **트랜잭션 관리**: `@Transactional`을 사용하면 두 기술이 동일한 트랜잭션에서 작동
2. **예외 처리**: JPA는 `PersistenceException`, JDBC는 `DataAccessException` 발생 - 통합 예외 처리 필요
3. **성능 고려**: 대량 데이터 처리 시 JdbcTemplate이 더 효율적일 수 있음
4. **영속성 컨텍스트**: JPA 작업 후 JDBC로 직접 DB 접근 시 영속성 컨텍스트와 불일치 가능성 있음

## 결론

Spring JPA와 JdbcTemplate을 함께 사용하면 JPA의 객체 지향적인 접근 방식과 JDBC의 유연한 SQL 실행을 모두 활용할 수 있습니다. 프로젝트 요구사항에 따라 각 기술의 장점을 적절히 조합하여 사용하는 것이 좋습니다. 특히 복잡한 보고서 쿼리나 대량 데이터 처리 시 JdbcTemplate을, 일반적인 CRUD 작업에는 JPA를 사용하는 것이 일반적인 패턴입니다.
