Java에서 한 줄에 있는 태그 형식의 데이터를 모두 찾는 방법을 자세히 설명해드리겠습니다.

## 1. 정규표현식을 이용한 방법 (가장 일반적)

### 기본적인 태그 찾기 패턴
```java
import java.util.regex.Matcher;
import java.util.regex.Pattern;

public class TagFinder {
    public static void main(String[] args) {
        String input = "<div>Hello</div> <span>World</span> <p>Java</p>";
        
        // 가장 기본적인 태그 패턴
        Pattern pattern = Pattern.compile("<[^>]+>");
        Matcher matcher = pattern.matcher(input);
        
        System.out.println("모든 태그 찾기:");
        while (matcher.find()) {
            System.out.println("찾은 태그: " + matcher.group());
        }
    }
}
```

### 다양한 태그 패턴 예제

```java
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import java.util.ArrayList;
import java.util.List;

public class AdvancedTagFinder {
    
    // 1. 모든 태그 찾기 (가장 기본)
    public static List<String> findAllTags(String input) {
        List<String> tags = new ArrayList<>();
        Pattern pattern = Pattern.compile("<[^>]+>");
        Matcher matcher = pattern.matcher(input);
        
        while (matcher.find()) {
            tags.add(matcher.group());
        }
        return tags;
    }
    
    // 2. 특정 태그만 찾기 (예: div 태그만)
    public static List<String> findDivTags(String input) {
        List<String> tags = new ArrayList<>();
        Pattern pattern = Pattern.compile("<div[^>]*>");
        Matcher matcher = pattern.matcher(input);
        
        while (matcher.find()) {
            tags.add(matcher.group());
        }
        return tags;
    }
    
    // 3. 닫는 태그 찾기
    public static List<String> findClosingTags(String input) {
        List<String> tags = new ArrayList<>();
        Pattern pattern = Pattern.compile("</[^>]+>");
        Matcher matcher = pattern.matcher(input);
        
        while (matcher.find()) {
            tags.add(matcher.group());
        }
        return tags;
    }
    
    // 4. 태그 내용까지 함께 추출
    public static List<String> findTagsWithContent(String input) {
        List<String> results = new ArrayList<>();
        Pattern pattern = Pattern.compile("<([^>]+)>(.*?)</\\1>");
        Matcher matcher = pattern.matcher(input);
        
        while (matcher.find()) {
            results.add("태그: " + matcher.group(1) + 
                       ", 내용: " + matcher.group(2));
        }
        return results;
    }
    
    // 5. 속성이 있는 태그 찾기
    public static List<String> findTagsWithAttributes(String input) {
        List<String> tags = new ArrayList<>();
        Pattern pattern = Pattern.compile("<\\w+[^>]*>");
        Matcher matcher = pattern.matcher(input);
        
        while (matcher.find()) {
            tags.add(matcher.group());
        }
        return tags;
    }
}
```

## 2. XML/HTML 파서 사용 (정확한 파싱 필요시)

```java
import javax.xml.parsers.*;
import org.w3c.dom.*;
import org.xml.sax.InputSource;
import java.io.StringReader;

public class XMLParserExample {
    public static void parseXMLTags(String xmlString) {
        try {
            DocumentBuilderFactory factory = DocumentBuilderFactory.newInstance();
            DocumentBuilder builder = factory.newDocumentBuilder();
            Document document = builder.parse(new InputSource(new StringReader(xmlString)));
            
            NodeList nodes = document.getElementsByTagName("*");
            
            for (int i = 0; i < nodes.getLength(); i++) {
                Node node = nodes.item(i);
                if (node.getNodeType() == Node.ELEMENT_NODE) {
                    System.out.println("태그 이름: " + node.getNodeName());
                    System.out.println("내용: " + node.getTextContent());
                }
            }
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

## 3. JSoup 라이브러리 사용 (HTML 파싱 전문)

```java
import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.jsoup.nodes.Element;
import org.jsoup.select.Elements;

public class JsoupExample {
    public static void findTagsWithJsoup(String html) {
        Document doc = Jsoup.parse(html);
        
        // 모든 태그 찾기
        Elements allTags = doc.select("*");
        for (Element tag : allTags) {
            System.out.println("태그: " + tag.tagName());
            System.out.println("내용: " + tag.text());
        }
        
        // 특정 태그만 찾기
        Elements divTags = doc.select("div");
        Elements spanTags = doc.select("span");
    }
}
```

## 4. 실용적인 사용 예제

```java
public class PracticalTagFinder {
    
    // 파일에서 태그 찾기
    public static void findTagsInFile(String filePath) {
        try {
            String content = new String(Files.readAllBytes(Paths.get(filePath)));
            List<String> tags = findAllTags(content);
            
            System.out.println("파일에서 찾은 태그들:");
            tags.forEach(System.out::println);
            
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
    
    // 태그 통계 분석
    public static void analyzeTags(String input) {
        Map<String, Integer> tagCount = new HashMap<>();
        Pattern pattern = Pattern.compile("<(/?)(\\w+)[^>]*>");
        Matcher matcher = pattern.matcher(input);
        
        while (matcher.find()) {
            String tagName = matcher.group(2);
            tagCount.put(tagName, tagCount.getOrDefault(tagName, 0) + 1);
        }
        
        System.out.println("태그 통계:");
        tagCount.forEach((tag, count) -> 
            System.out.println(tag + ": " + count + "개"));
    }
}
```

## 5. 성능 최적화 팁

```java
public class OptimizedTagFinder {
    
    // Pattern을 재사용하여 성능 향상
    private static final Pattern TAG_PATTERN = Pattern.compile("<[^>]+>");
    
    public static List<String> findTagsOptimized(String input) {
        List<String> tags = new ArrayList<>();
        Matcher matcher = TAG_PATTERN.matcher(input);
        
        while (matcher.find()) {
            tags.add(matcher.group());
        }
        return tags;
    }
    
    // 대용량 데이터 처리 시 스트림 사용
    public static List<String> findTagsStream(String input) {
        return TAG_PATTERN.matcher(input)
                .results()
                .map(MatchResult::group)
                .collect(Collectors.toList());
    }
}
```

## 주의사항

1. **정규표현식 한계**: 매우 복잡한 HTML/XML은 정규표현식으로 완벽히 파싱하기 어렵습니다.
2. **성능**: 대용량 데이터에서는 XML 파서나 JSoup 사용을 권장합니다.
3. **보안**: 외부 입력을 파싱할 때는 XXE(XML External Entity) 공격에 주의하세요.

가장 추천하는 방법은 **간단한 태그 찾기에는 정규표현식**, **정확한 파싱이 필요하면 JSoup**을 사용하는 것입니다.
