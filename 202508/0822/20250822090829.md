# Tablesaw의 groupBy 사용법

Tablesaw는 Java용 데이터 프레임 라이브러리로, 데이터 그룹화 작업을 쉽게 수행할 수 있습니다. groupBy 기능에 대해 자세히 설명해 드리겠습니다.

## 기본적인 groupBy 사용법

### 1. 테이블 생성 및 데이터 준비

```java
import tech.tablesaw.api.Table;
import tech.tablesaw.api.StringColumn;
import tech.tablesaw.api.IntColumn;
import tech.tablesaw.api.DoubleColumn;

// 샘플 데이터 생성
String[] categories = {"A", "B", "A", "C", "B", "A", "C"};
int[] values = {10, 20, 15, 30, 25, 12, 35};
double[] prices = {100.5, 200.3, 150.2, 300.1, 250.4, 120.6, 350.7};

Table table = Table.create("Sample Data")
    .addColumns(
        StringColumn.create("Category", categories),
        IntColumn.create("Value", values),
        DoubleColumn.create("Price", prices)
    );

System.out.println(table.print());
```

### 2. 기본 그룹화

```java
import tech.tablesaw.api.Table;
import tech.tablesaw.groupby.GroupBy;

// Category로 그룹화
Table grouped = table.groupBy("Category").aggregate("Value", "sum");
System.out.println("Sum by Category:");
System.out.println(grouped.print());
```

### 3. 여러 집계 함수 사용

```java
// 여러 집계 함수 적용
Table result = table.groupBy("Category")
    .aggregate(
        "Value", "sum",    // 합계
        "Value", "mean",   // 평균
        "Value", "count",  // 개수
        "Price", "max"     // 최대값
    );

System.out.println("Multiple aggregations:");
System.out.println(result.print());
```

## 여러 컬럼으로 그룹화

```java
// 더 많은 데이터 추가
String[] regions = {"North", "South", "North", "South", "North", "South", "North"};
table.addColumn(StringColumn.create("Region", regions));

// 여러 컬럼으로 그룹화
Table multiGrouped = table.groupBy("Category", "Region")
    .aggregate("Value", "sum", "Price", "mean");

System.out.println("Grouped by Category and Region:");
System.out.println(multiGrouped.print());
```

## 사용자 정의 집계 함수

```java
import tech.tablesaw.aggregate.AggregateFunction;
import tech.tablesaw.api.IntColumn;

// 사용자 정의 집계 함수 생성
AggregateFunction<Integer, IntColumn> rangeFunction = 
    new AggregateFunction<Integer, IntColumn>("range") {
        @Override
        public Integer aggregate(IntColumn column) {
            return column.max() - column.min();
        }
        
        @Override
        public String functionName() {
            return "range";
        }
    };

// 사용자 정의 함수 사용
Table customAgg = table.groupBy("Category")
    .aggregate(rangeFunction.onColumn("Value"));

System.out.println("Custom range aggregation:");
System.out.println(customAgg.print());
```

## 그룹화 후 데이터 접근

```java
import tech.tablesaw.groupby.Group;
import java.util.List;

// Group 객체로 직접 접근
List<Group> groups = table.groupBy("Category").getGroups();

for (Group group : groups) {
    String category = group.getGroupKey("Category");
    Table groupTable = group.asTable();
    
    System.out.println("Category: " + category);
    System.out.println("Group size: " + groupTable.rowCount());
    System.out.println("Group data:");
    System.out.println(groupTable.print());
    System.out.println("-------------------");
}
```

## 실전 예제

```java
// 실전 예제: 영업 데이터 분석
String[] products = {"Laptop", "Phone", "Tablet", "Laptop", "Phone", "Tablet", "Laptop"};
String[] months = {"Jan", "Jan", "Jan", "Feb", "Feb", "Feb", "Mar"};
int[] sales = {150, 200, 100, 170, 220, 120, 160};
double[] revenues = {75000, 60000, 30000, 85000, 66000, 36000, 80000};

Table salesData = Table.create("Sales Data")
    .addColumns(
        StringColumn.create("Product", products),
        StringColumn.create("Month", months),
        IntColumn.create("Sales", sales),
        DoubleColumn.create("Revenue", revenues)
    );

// 제품별 월별 집계
Table salesSummary = salesData.groupBy("Product", "Month")
    .aggregate(
        "Sales", "sum",
        "Revenue", "sum",
        "Sales", "mean"
    );

System.out.println("Sales Summary:");
System.out.println(salesSummary.print());

// 제품별 총 매출
Table productPerformance = salesData.groupBy("Product")
    .aggregate(
        "Revenue", "sum",
        "Sales", "sum"
    ).sortDescendingOn("Revenue sum");

System.out.println("Product Performance:");
System.out.println(productPerformance.print());
```

## 성능 최적화 팁

```java
// 1. 필요한 컬럼만 선택
Table optimized = table.selectColumns("Category", "Value", "Price");

// 2. 인덱스 생성
optimized.column("Category").setName("Category_indexed");

// 3. 큰 데이터셋의 경우 배치 처리
int batchSize = 1000;
for (int i = 0; i < optimized.rowCount(); i += batchSize) {
    Table batch = optimized.where(optimized.intColumn("rowIndex")
        .isBetween(i, Math.min(i + batchSize - 1, optimized.rowCount() - 1)));
    
    Table batchResult = batch.groupBy("Category").aggregate("Value", "sum");
    // 배치 결과 처리
}
```

## 주의사항

1. **메모리 사용**: 큰 데이터셋을 그룹화할 때는 메모리 사용량에 주의
2. **널 값**: 그룹화하기 전에 널 값을 처리하는 것이 좋음
3. **성능**: 많은 그룹을 생성하면 성능이 저하될 수 있음
