네, numpy 배열의 동작 방식을 자세히 설명해드리겠습니다.

## 1. Numpy 배열의 핵심 개념

### 1.1 기본 구조
```python
import numpy as np

# 1차원 배열
arr1d = np.array([1, 2, 3, 4, 5])
print(arr1d.shape)  # (5,) - 5개의 요소

# 2차원 배열
arr2d = np.array([[1, 2, 3], [4, 5, 6]])
print(arr2d.shape)  # (2, 3) - 2행 3열
```

### 1.2 Homogeneous 데이터 타입
- 모든 요소가 동일한 데이터 타입을 가짐
- 메모리 효율성과 연산 속도 향상

```python
arr = np.array([1, 2, 3], dtype=np.float32)
print(arr.dtype)  # float32
```

## 2. 메모리 구조와 저장 방식

### 2.1 연속 메모리 블록
```python
arr = np.array([1, 2, 3, 4, 5])
# 메모리 레이아웃: [1][2][3][4][5] (연속된 주소)
```

### 2.2 다차원 배열의 메모리 배치
```python
arr_2d = np.array([[1, 2, 3], [4, 5, 6]])
# 메모리 레이아웃: [1][2][3][4][5][6] (행 우선 저장)
```

## 3. 인덱싱과 슬라이싱

### 3.1 기본 인덱싱
```python
arr = np.array([10, 20, 30, 40, 50])

# 단일 요소 접근
print(arr[2])  # 30

# 슬라이싱
print(arr[1:4])  # [20, 30, 40]
```

### 3.2 불리언 인덱싱
```python
arr = np.array([1, 2, 3, 4, 5])
mask = arr > 3
print(arr[mask])  # [4, 5]
```

### 3.3 팬시 인덱싱
```python
arr = np.array([10, 20, 30, 40, 50])
indices = [0, 2, 4]
print(arr[indices])  # [10, 30, 50]
```

## 4. 브로드캐스팅 (Broadcasting)

### 4.1 개념
- 다른 shape의 배열 간 연산을 가능하게 함
- 자동으로 배열을 확장하여 연산 수행

```python
# 스칼라 브로드캐스팅
arr = np.array([1, 2, 3])
result = arr + 5  # [6, 7, 8]

# 배열 브로드캐스팅
a = np.array([[1], [2], [3]])  # shape: (3, 1)
b = np.array([10, 20, 30])     # shape: (3,)
result = a + b  # [[11, 21, 31], [12, 22, 32], [13, 23, 33]]
```

### 4.2 브로드캐스팅 규칙
1. 차원 수 맞추기 (앞에 1 추가)
2. 각 차원의 크기가 1이거나 같아야 함
3. 크기가 1인 차원은 반복됨

## 5. 뷰(View) vs 복사(Copy)

### 5.1 뷰 (View)
```python
arr = np.array([1, 2, 3, 4, 5])
view = arr[1:4]  # 원본 데이터의 뷰
view[0] = 99
print(arr)  # [1, 99, 3, 4, 5] - 원본도 변경됨
```

### 5.2 복사 (Copy)
```python
arr = np.array([1, 2, 3, 4, 5])
copy = arr[1:4].copy()  # 새로운 배열 생성
copy[0] = 99
print(arr)  # [1, 2, 3, 4, 5] - 원본 변경 없음
```

## 6. 벡터화 연산

### 6.1 요소별 연산
```python
arr = np.array([1, 2, 3, 4, 5])

# 벡터화된 연산
result = arr * 2 + 1  # [3, 5, 7, 9, 11]

# 반복문 없이 전체 요소에 적용
sqrt_arr = np.sqrt(arr)  # 제곱근 계산
```

### 6.2 유니버설 함수 (ufunc)
```python
arr = np.array([1, 2, 3])

# 수학 함수
print(np.sin(arr))    # 사인 함수
print(np.exp(arr))    # 지수 함수
print(np.log(arr))    # 로그 함수

# 이항 연산
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
print(np.add(a, b))   # [5, 7, 9]
```
