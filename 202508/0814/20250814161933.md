# Grok 패턴 라이브러리를 Maven 프로젝트에 추가하는 방법

Grok 패턴 라이브러리는 로그 파싱에 유용한 정규 표현식 패턴 컬렉션입니다. Maven 프로젝트에 Grok 패턴 라이브러리를 추가하는 방법을 설명드리겠습니다.

## 1. 주요 Grok 라이브러리

주로 사용되는 Grok 관련 라이브러리는 다음과 같습니다:

1. **logstash-grok** (Elastic Stack의 Logstash에서 사용)
2. **java-grok** (Java 전용 구현체)
3. **org.logstashplugins:java-grok** (Logstash 플러그인 버전)

## 2. Maven 의존성 추가 방법

### 옵션 1: java-grok 라이브러리 사용

```xml
<dependency>
    <groupId>io.thekraken</groupId>
    <artifactId>grok</artifactId>
    <version>0.1.5</version>
</dependency>
```

### 옵션 2: Logstash의 Grok 구현체 사용

```xml
<dependency>
    <groupId>org.logstashplugins</groupId>
    <artifactId>java-grok</artifactId>
    <version>0.1.0</version>
</dependency>
```

### 옵션 3: Elastic의 Grok 프로세서 (최신 버전)

```xml
<dependency>
    <groupId>co.elastic.logging</groupId>
    <artifactId>log4j2-grok</artifactId>
    <version>2.0.0</version>
</dependency>
```

## 3. 기본 사용 예제

의존성 추가 후 간단한 사용 예제:

```java
import io.thekraken.grok.api.Grok;
import io.thekraken.grok.api.Match;
import io.thekraken.grok.api.exception.GrokException;

public class GrokExample {
    public static void main(String[] args) throws GrokException {
        Grok grok = new Grok();
        
        // 기본 패턴 로드
        grok.addPatternFromFile("/path/to/patterns/grok-patterns");
        
        // 사용자 정의 패턴 추가
        grok.addPattern("MY_PATTERN", "\\d{4}-\\d{2}-\\d{2}");
        
        // 컴파일할 패턴 지정
        grok.compile("%{MY_PATTERN:date} %{WORD:level} %{GREEDYDATA:message}");
        
        // 로그 메시지 파싱
        String log = "2023-05-15 ERROR Something went wrong";
        Match match = grok.match(log);
        match.captures();
        
        System.out.println(match.toMap());
        // {date=2023-05-15, level=ERROR, message=Something went wrong}
    }
}
```

## 4. 패턴 파일 위치

Grok은 일반적으로 기본 패턴 파일이 필요합니다. 이 파일은 다음 위치에서 찾을 수 있습니다:

1. Logstash 설치 디렉토리의 `patterns` 폴더
2. GitHub 저장소: [logstash-patterns-core](https://github.com/logstash-plugins/logstash-patterns-core)
3. 프로젝트 리소스 폴더에 직접 복사

## 5. 주의사항

1. 버전 호환성을 확인하세요. 특히 Logstash와 함께 사용할 경우 버전 일치가 중요합니다.
2. 성능이 중요한 경우 Grok 컴파일 결과를 캐싱하는 것이 좋습니다.
3. 복잡한 패턴은 CPU 사용량이 높을 수 있으니 주의가 필요합니다.

필요한 경우 더 구체적인 정보를 알려주시면 해당 부분을 더 자세히 설명드리겠습니다.
