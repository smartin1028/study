# Java 로그 파일 분리 및 타임스탬프 기준 병합 유틸리티

다음은 Java로 작성된 로그 파일 처리 유틸리티로, 타임스탬프를 기준으로 여러 줄의 로그를 하나의 줄로 병합하는 기능을 제공합니다.

## 전체 코드

```java
import java.io.*;
import java.nio.file.*;
import java.time.*;
import java.time.format.*;
import java.util.*;
import java.util.regex.*;

public class LogMergerUtility {
    // 로그 파일에서 타임스탬프를 추출하기 위한 정규식 패턴
    private static final String TIMESTAMP_PATTERN = 
        "^\\[(\\d{4}-\\d{2}-\\d{2} \\d{2}:\\d{2}:\\d{2}\\.\\d{3})\\]";
    private static final DateTimeFormatter TIMESTAMP_FORMATTER = 
        DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss.SSS");

    public static void main(String[] args) {
        if (args.length < 2) {
            System.out.println("Usage: java LogMergerUtility <inputFile> <outputFile>");
            return;
        }

        String inputFilePath = args[0];
        String outputFilePath = args[1];

        try {
            processLogFile(inputFilePath, outputFilePath);
            System.out.println("Log file processed successfully!");
        } catch (IOException e) {
            System.err.println("Error processing log file: " + e.getMessage());
        }
    }

    public static void processLogFile(String inputPath, String outputPath) throws IOException {
        Path inputFile = Paths.get(inputPath);
        Path outputFile = Paths.get(outputPath);

        // 입력 파일이 존재하는지 확인
        if (!Files.exists(inputFile)) {
            throw new FileNotFoundException("Input file not found: " + inputPath);
        }

        // 출력 디렉토리가 존재하는지 확인하고 없으면 생성
        Path outputDir = outputFile.getParent();
        if (outputDir != null && !Files.exists(outputDir)) {
            Files.createDirectories(outputDir);
        }

        // 로그 처리
        try (BufferedReader reader = Files.newBufferedReader(inputFile);
             BufferedWriter writer = Files.newBufferedWriter(outputFile)) {
            
            String currentTimestamp = null;
            StringBuilder mergedLines = new StringBuilder();
            Pattern pattern = Pattern.compile(TIMESTAMP_PATTERN);

            String line;
            while ((line = reader.readLine()) != null) {
                Matcher matcher = pattern.matcher(line);
                
                if (matcher.find()) {
                    // 새로운 타임스탬프 발견 - 이전 내용을 기록
                    if (currentTimestamp != null) {
                        writer.write("[" + currentTimestamp + "] " + mergedLines.toString());
                        writer.newLine();
                    }
                    
                    // 새 타임스탬프와 내용으로 초기화
                    currentTimestamp = matcher.group(1);
                    mergedLines = new StringBuilder(line.substring(matcher.end()).trim());
                } else if (currentTimestamp != null) {
                    // 동일한 타임스탬프의 연속된 줄 - 내용 추가
                    mergedLines.append(" ").append(line.trim());
                } else {
                    // 타임스탬프 없는 첫 줄 - 그대로 기록
                    writer.write(line);
                    writer.newLine();
                }
            }
            
            // 마지막으로 처리 중이던 내용 기록
            if (currentTimestamp != null) {
                writer.write("[" + currentTimestamp + "] " + mergedLines.toString());
                writer.newLine();
            }
        }
    }
}
```

## 기능 설명

1. **타임스탬프 인식**: 정규식을 사용하여 `[yyyy-MM-dd HH:mm:ss.SSS]` 형식의 타임스탬프를 인식합니다.
2. **로그 병합**: 동일한 타임스탬프를 가진 여러 줄의 로그를 하나의 줄로 병합합니다.
3. **입출력 처리**: 지정된 입력 파일을 읽고 처리 결과를 출력 파일에 저장합니다.

## 사용 방법

1. 컴파일:
   ```
   javac LogMergerUtility.java
   ```

2. 실행:
   ```
   java LogMergerUtility input.log output.log
   ```

## 확장 가능한 기능

1. **다양한 타임스탬프 형식 지원**: 다른 형식의 타임스탬프를 처리하려면 `TIMESTAMP_PATTERN`과 `TIMESTAMP_FORMATTER`를 수정하세요.
2. **병합 방식 커스터마이징**: 줄바꿈 문자를 유지하려면 `mergedLines.append(" ").append(line.trim())` 부분을 수정하세요.
3. **대용량 파일 처리**: 메모리 효율성을 높이려면 라인 단위로 처리하는 방식을 유지하세요.
