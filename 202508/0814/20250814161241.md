# 자바에서 로그를 분할(Split)하는 라이브러리

자바에서 로그를 분할(split)하는 작업은 여러 가지 방법으로 수행할 수 있으며, 특정 라이브러리를 사용하거나 기본 Java 기능을 활용할 수 있습니다.

## 1. 기본 Java 기능 사용

### String.split() 메서드
```java
String logEntry = "2023-11-15 12:30:45 [INFO] User logged in";
String[] parts = logEntry.split(" "); // 공백 기준 분할
```

### StringTokenizer 클래스
```java
StringTokenizer tokenizer = new StringTokenizer(logEntry, " ");
while (tokenizer.hasMoreTokens()) {
    System.out.println(tokenizer.nextToken());
}
```

## 2. 전문 로그 처리 라이브러리

### Apache Commons Lang
- `StringUtils` 클래스의 split 메서드 제공
```java
String[] parts = StringUtils.split(logEntry, " ");
```

### Log4j / Logback
- 로그 메시지를 구조화된 형식으로 파싱할 수 있음
- PatternLayout을 사용하여 로그 포맷 정의 가능

### Logstash Log4j Appender
- 로그를 JSON 형식으로 변환하여 분할된 필드로 처리 가능

### Grok 패턴 라이브러리
- logstash-grok, java-grok 등 Grok 패턴을 사용하여 복잡한 로그 분할 가능
```java
GrokCompiler compiler = GrokCompiler.newInstance();
compiler.registerPatternFromClasspath("/patterns/patterns");
Grok grok = compiler.compile("%{TIMESTAMP_ISO8601:timestamp} %{LOGLEVEL:level} %{GREEDYDATA:message}");
```

## 3. 정규 표현식 활용

```java
Pattern pattern = Pattern.compile("(\\d{4}-\\d{2}-\\d{2}) (\\d{2}:\\d{2}:\\d{2}) \\[(\\w+)\\] (.*)");
Matcher matcher = pattern.matcher(logEntry);
if (matcher.find()) {
    String date = matcher.group(1);
    String time = matcher.group(2);
    String level = matcher.group(3);
    String message = matcher.group(4);
}
```

## 4. JSON 로그 처리

```java
// Jackson 라이브러리 사용 예
ObjectMapper mapper = new ObjectMapper();
JsonNode node = mapper.readTree(logEntry);
String level = node.get("level").asText();
```

## 선택 가이드

1. 간단한 분할: `String.split()` 또는 `StringTokenizer`
2. 복잡한 로그 포맷: 정규 표현식 또는 Grok 패턴
3. 구조화된 로그(JSON 등): Jackson/Gson 같은 JSON 파서
4. 대규모 로그 처리: Logstash, Fluentd 등의 전문 도구

특히 최근에는 구조화된 로깅(JSON 형식)이 점점 더 많이 사용되고 있어, JSON 파싱 라이브러리를 활용하는 것이 효율적인 경우가 많습니다.
