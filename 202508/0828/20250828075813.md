# Python sklearn LabelEncoder란?

## 개요

LabelEncoder는 scikit-learn 라이브러리에서 제공하는 유틸리티 클래스로, **범주형(categorical) 레이블(문자열 또는 정수)을 숫자 형식으로 변환**하는 데 사용됩니다. 주로 분류 문제에서 타겟 변수(y)의 레이블을 인코딩할 때 활용됩니다.

## 주요 기능

### 1. 기본 사용법
```python
from sklearn.preprocessing import LabelEncoder

# LabelEncoder 객체 생성
le = LabelEncoder()

# 레이블 데이터
labels = ['cat', 'dog', 'bird', 'cat', 'bird']

# 레이블 인코딩
encoded_labels = le.fit_transform(labels)
print(encoded_labels)  # 출력: [0 1 2 0 2]

# 인코딩된 레이블을 원본으로 복원
original_labels = le.inverse_transform(encoded_labels)
print(original_labels)  # 출력: ['cat' 'dog' 'bird' 'cat' 'bird']
```

### 2. 클래스 정보 확인
```python
# 인코딩된 클래스 이름 확인
print(le.classes_)  # 출력: ['bird' 'cat' 'dog']

# 클래스별 매핑 정보
for i, class_name in enumerate(le.classes_):
    print(f"{class_name} -> {i}")
# 출력:
# bird -> 0
# cat -> 1
# dog -> 2
```

## 작동 방식

LabelEncoder는 다음과 같은 방식으로 작동합니다:

1. **고유한 클래스 식별**: 입력 데이터에서 모든 고유한 클래스를 찾습니다
2. **알파벳 순 정렬**: 클래스들을 알파벳 순서로 정렬합니다
3. **숫자 매핑**: 각 클래스에 0부터 시작하는 정수 값을 할당합니다

## 주의사항

### 1. 순서 의미 문제
```python
# 주의: LabelEncoder는 순서를 의미하지 않음
size_labels = ['small', 'medium', 'large']
le.fit(size_labels)
encoded = le.transform(size_labels)
print(encoded)  # 출력: [2 1 0] - 알파벳 순으로 정렬됨
```

순서가 중요한 경우에는 `OrdinalEncoder`를 사용해야 합니다.

### 2. 새로운 데이터 처리
```python
# 새로운 데이터 인코딩 시 주의
new_data = ['dog', 'cat', 'rabbit']  # rabbit은 학습되지 않은 클래스

try:
    le.transform(new_data)  # ValueError 발생
except ValueError as e:
    print(f"Error: {e}")
```

## 실제 적용 예제

### 머신러닝 파이프라인에서의 사용
```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier

# 데이터 로드
iris = load_iris()
X, y = iris.data, iris.target_names[iris.target]

# 레이블 인코딩
le = LabelEncoder()
y_encoded = le.fit_transform(y)

# 데이터 분할
X_train, X_test, y_train, y_test = train_test_split(
    X, y_encoded, test_size=0.2, random_state=42
)

# 모델 학습 및 예측
model = RandomForestClassifier()
model.fit(X_train, y_train)
predictions = model.predict(X_test)

# 예측 결과 디코딩
predicted_labels = le.inverse_transform(predictions)
print(predicted_labels)
```

## 대안 Encoder 비교

| Encoder | 용도 | 특징 |
|---------|------|------|
| **LabelEncoder** | 타겟 변수(y) 인코딩 | 단일 열, 0부터 시작하는 정수 |
| **OrdinalEncoder** | 특성 변수(X) 인코딩 | 다중 열, 사용자 정의 순서 가능 |
| **OneHotEncoder** | 명목형 변수 인코딩 | 다중 열, 원-핫 인코딩 |

## 결론

LabelEncoder는 **분류 문제에서 타겟 레이블을 숫자로 변환**할 때 유용한 도구입니다. 하지만 다음과 같은 점을 주의해야 합니다:

1. **순서가 없는 명목형 변수**에 적합합니다
2. **타겟 변수(y)에만 사용**하는 것이 좋습니다
3. **학습 데이터에 없는 새로운 클래스**는 처리할 수 없습니다
4. 순서가 중요한 경우에는 `OrdinalEncoder`를 사용해야 합니다

scikit-learn의 전처리 파이프라인에서 LabelEncoder는 머신러닝 모델이 이해할 수 있는 형식으로 레이블 데이터를 변환하는 중요한 역할을 수행합니다.
