네, Java에서 Escape 처리를 위한 라이브러리를 자세히 설명해 드리겠습니다.

## 주요 Escape 처리 라이브러리

### 1. **Apache Commons Text - StringEscapeUtils**
**Apache Commons에도 있습니다!** 가장 추천하는 라이브러리입니다.

```xml
<!-- Maven 의존성 -->
<dependency>
    <groupId>org.apache.commons</groupId>
    <artifactId>commons-text</artifactId>
    <version>1.10.0</version>
</dependency>
```

**사용 예시:**
```java
import org.apache.commons.text.StringEscapeUtils;

// HTML Escape
String html = "<div>Hello & World</div>";
String escapedHtml = StringEscapeUtils.escapeHtml4(html);
// 결과: &lt;div&gt;Hello &amp; World&lt;/div&gt;

// HTML Unescape
String unescaped = StringEscapeUtils.unescapeHtml4(escapedHtml);

// XML Escape
String xml = "<message>Hello & World</message>";
String escapedXml = StringEscapeUtils.escapeXml11(xml);

// CSV Escape
String csv = "Hello, \"World\"";
String escapedCsv = StringEscapeUtils.escapeCsv(csv);
```

### 2. **OWASP Java Encoder**
보안에 특화된 라이브러리로 XSS 방지에 최적화됨

```xml
<dependency>
    <groupId>org.owasp.encoder</groupId>
    <artifactId>encoder</artifactId>
    <version>1.2.3</version>
</dependency>
```

```java
import org.owasp.encoder.Encode;

// HTML 컨텍스트
String safeHtml = Encode.forHtml("<script>alert('xss')</script>");

// HTML 속성 컨텍스트
String safeAttr = Encode.forHtmlAttribute("user\"input");

// JavaScript 컨텍스트
String safeJs = Encode.forJavaScript("user'input");

// CSS 컨텍스트
String safeCss = Encode.forCssString("user\"input");
```

### 3. **Spring Framework의 HtmlUtils**
Spring 프로젝트에서 사용 시 편리함

```java
import org.springframework.web.util.HtmlUtils;

String html = "<div>Test & Test</div>";
String escaped = HtmlUtils.htmlEscape(html);
String escapedDecimal = HtmlUtils.htmlEscapeDecimal(html);
String escapedHex = HtmlUtils.htmlEscapeHex(html);
```

### 4. **JSON Escape - Jackson Library**
```java
import com.fasterxml.jackson.core.io.JsonStringEncoder;

JsonStringEncoder encoder = JsonStringEncoder.getInstance();
char[] escaped = encoder.quoteAsString("Hello \"World\"");
String result = new String(escaped);
```

## Apache Commons 관련 참고사항

**주의:** 예전에는 `Apache Commons Lang`의 `StringEscapeUtils`를 사용했지만,  
현재는 **Apache Commons Text**로 이관되었습니다.

```java
// 구버전 (Deprecated)
import org.apache.commons.lang3.StringEscapeUtils;

// 신버전 (권장)
import org.apache.commons.text.StringEscapeUtils;
```

## 선택 가이드

1. **일반적인用途**: Apache Commons Text
2. **보안-critical 애플리케이션**: OWASP Java Encoder
3. **Spring 프로젝트**: Spring HtmlUtils
4. **JSON 처리**: Jackson Library

## 사용 시 주의사항

- **컨텍스트 인식**: HTML, JavaScript, CSS 등 컨텍스트에 맞는 escape 방법 선택
- **이중 escape 방지**: 이미 escape된 데이터를 다시 escape하지 않도록 주의
- **성능 고려**: 대량 처리 시 라이브러리 성능 비교 권장

Apache Commons Text가 가장 범용적으로 사용하기 좋으며, 보안 요구사항이 높을 경우 OWASP 라이브러리를 추가로 고려해보세요.
