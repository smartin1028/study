# Java ObjectMapper 기능 상세 설명

## ObjectMapper란?

ObjectMapper는 Jackson 라이브러리의 핵심 클래스로, **Java 객체와 JSON 데이터 간의 변환(직렬화/역직렬화)**을 처리합니다. 주로 REST API 개발에서 요청/응답 데이터 변환에 사용됩니다.

## 주요 기능

### 1. 직렬화 (Serialization) - Java 객체 → JSON
```java
ObjectMapper objectMapper = new ObjectMapper();
User user = new User("John", 30, "john@example.com");

// 객체를 JSON 문자열로 변환
String json = objectMapper.writeValueAsString(user);
// 결과: {"name":"John","age":30,"email":"john@example.com"}

// JSON 파일로 저장
objectMapper.writeValue(new File("user.json"), user);
```

### 2. 역직렬화 (Deserialization) - JSON → Java 객체
```java
String json = "{\"name\":\"John\",\"age\":30,\"email\":\"john@example.com\"}";

// JSON 문자열을 객체로 변환
User user = objectMapper.readValue(json, User.class);

// JSON 파일에서 객체로 변환
User userFromFile = objectMapper.readValue(new File("user.json"), User.class);
```

### 3. 컬렉션 처리
```java
// List 변환
List<User> users = objectMapper.readValue(jsonArray, new TypeReference<List<User>>() {});

// Map 변환
Map<String, Object> map = objectMapper.readValue(json, new TypeReference<Map<String, Object>>() {});
```

### 4. 구성 옵션 (Configuration)

#### 읽기/쓰기 옵션
```java
// 알 수 없는 속성 무시 (JSON에 필드가 있지만 Java 객체에는 없는 경우)
objectMapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);

// 빈 객체 허용
objectMapper.configure(SerializationFeature.FAIL_ON_EMPTY_BEANS, false);

// 날짜 형식 설정
objectMapper.setDateFormat(new SimpleDateFormat("yyyy-MM-dd HH:mm:ss"));
```

#### pretty print 설정
```java
// 가독성 좋은 JSON 출력
String prettyJson = objectMapper.writerWithDefaultPrettyPrinter().writeValueAsString(user);
```

### 5. 어노테이션 지원

Jackson은 다양한 어노테이션을 통해 변환 과정을 제어합니다:

```java
public class User {
    @JsonProperty("user_name")  // JSON 필드명 매핑
    private String name;
    
    @JsonIgnore                 // 직렬화/역직렬화에서 제외
    private String password;
    
    @JsonFormat(pattern = "yyyy-MM-dd")
    private Date birthDate;
    
    @JsonInclude(JsonInclude.Include.NON_NULL) // null 값 제외
    private String optionalField;
}
```

### 6. 커스텀 직렬화/역직렬화

```java
// 커스텀 직렬화기
public class CustomSerializer extends JsonSerializer<User> {
    @Override
    public void serialize(User value, JsonGenerator gen, SerializerProvider provider) {
        gen.writeStartObject();
        gen.writeStringField("fullName", value.getName().toUpperCase());
        gen.writeEndObject();
    }
}

// 커스텀 역직렬화기
public class CustomDeserializer extends JsonDeserializer<User> {
    @Override
    public User deserialize(JsonParser p, DeserializationContext ctxt) {
        // 커스텀 로직 구현
    }
}

// 어노테이션으로 등록
@JsonSerialize(using = CustomSerializer.class)
@JsonDeserialize(using = CustomDeserializer.class)
public class User {
    // ...
}
```

### 7. 트리 모델 (Tree Model) 접근

```java
// JSON을 트리 구조로 파싱
JsonNode rootNode = objectMapper.readTree(json);

// 특정 필드 접근
String name = rootNode.get("name").asText();
int age = rootNode.get("age").asInt();

// 배열 처리
JsonNode emails = rootNode.get("emails");
for (JsonNode email : emails) {
    System.out.println(email.asText());
}
```

## 성능 최적화 팁

1. **ObjectMapper 재사용**: ObjectMapper는 thread-safe하므로 인스턴스를 재사용하는 것이 좋습니다.
2. **정적 인스턴스**:
```java
public class JsonUtils {
    private static final ObjectMapper objectMapper = new ObjectMapper();
    static {
        objectMapper.configure(DeserializationFeature.FAIL_ON_UNKNOWN_PROPERTIES, false);
    }
}
```

3. **미리 구성하기**: 반복적인 설정은 static 블록에서 미리 구성

## 주의사항

- **기본 생성자 필요**: 역직렬화를 위해서는 기본 생성자가 필요합니다.
- **Getter/Setter**: private 필드의 경우 getter/setter 메서드가 필요합니다.
- **순환 참조 주의**: `@JsonIgnore`로 순환 참조를 방지해야 합니다.

ObjectMapper는 Jackson 라이브러리의 강력한 기능을 제공하며, 적절히 활용하면 JSON 처리 작업을 효율적으로 수행할 수 있습니다.
