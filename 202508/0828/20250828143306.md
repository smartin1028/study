# Spring 없이 Java에서 Elasticsearch 9.x 사용하기 (HTTPS/HTTP)

## 1. Maven/Gradle 의존성 추가

### Maven
```xml
<dependency>
    <groupId>co.elastic.clients</groupId>
    <artifactId>elasticsearch-java</artifactId>
    <version>9.0.0</version>
</dependency>
<dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.15.0</version>
</dependency>
```

### Gradle
```gradle
implementation 'co.elastic.clients:elasticsearch-java:9.0.0'
implementation 'com.fasterxml.jackson.core:jackson-databind:2.15.0'
```

## 2. HTTPS 연결 (SSL 인증서 있는 경우)

```java
import co.elastic.clients.elasticsearch.ElasticsearchClient;
import co.elastic.clients.json.jackson.JacksonJsonpMapper;
import co.elastic.clients.transport.ElasticsearchTransport;
import co.elastic.clients.transport.rest_client.RestClientTransport;
import org.apache.http.HttpHost;
import org.apache.http.auth.AuthScope;
import org.apache.http.auth.UsernamePasswordCredentials;
import org.apache.http.client.CredentialsProvider;
import org.apache.http.impl.client.BasicCredentialsProvider;
import org.apache.http.ssl.SSLContextBuilder;
import org.apache.http.ssl.SSLContexts;
import org.elasticsearch.client.RestClient;

import javax.net.ssl.SSLContext;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Paths;
import java.security.KeyStore;
import java.security.cert.Certificate;
import java.security.cert.CertificateFactory;

public class ElasticsearchHTTPSClient {

    public static ElasticsearchClient createHttpsClient() throws Exception {
        // SSL 컨텍스트 생성
        SSLContext sslContext = createSSLContext();
        
        // 인증 정보 제공자 설정
        final CredentialsProvider credentialsProvider = new BasicCredentialsProvider();
        credentialsProvider.setCredentials(AuthScope.ANY,
                new UsernamePasswordCredentials("username", "password"));

        // RestClient 생성
        RestClient restClient = RestClient.builder(
                new HttpHost("localhost", 9200, "https"))
                .setHttpClientConfigCallback(httpClientBuilder -> httpClientBuilder
                        .setSSLContext(sslContext)
                        .setDefaultCredentialsProvider(credentialsProvider))
                .build();

        // Transport 생성
        ElasticsearchTransport transport = new RestClientTransport(
                restClient, new JacksonJsonpMapper());

        return new ElasticsearchClient(transport);
    }

    private static SSLContext createSSLContext() throws Exception {
        // CA 인증서 로드
        CertificateFactory factory = CertificateFactory.getInstance("X.509");
        Certificate trustedCa;
        try (InputStream is = Files.newInputStream(Paths.get("/path/to/ca.crt"))) {
            trustedCa = factory.generateCertificate(is);
        }

        // 키스토어에 인증서 추가
        KeyStore trustStore = KeyStore.getInstance("pkcs12");
        trustStore.load(null, null);
        trustStore.setCertificateEntry("ca", trustedCa);

        // SSL 컨텍스트 빌드
        SSLContextBuilder sslBuilder = SSLContexts.custom()
                .loadTrustMaterial(trustStore, null);
        return sslBuilder.build();
    }
}
```

## 3. HTTP 연결 (SSL 없는 경우)

```java
import co.elastic.clients.elasticsearch.ElasticsearchClient;
import co.elastic.clients.json.jackson.JacksonJsonpMapper;

import org.apache.http.client.CredentialsProvider;
import org.apache.http.impl.client.BasicCredentialsProvider;
import org.elasticsearch.client.RestClient;

public class ElasticsearchHTTPClient {

    public static ElasticsearchClient createHttpClient() {
        // 인증 정보 제공자 설정 (필요한 경우)
        final CredentialsProvider credentialsProvider = new BasicCredentialsProvider();
        credentialsProvider.setCredentials(AuthScope.ANY,
                new UsernamePasswordCredentials("username", "password"));

        // RestClient 생성 (HTTP)
        RestClient restClient = RestClient.builder(
                new HttpHost("localhost", 9200, "http"))
                .setHttpClientConfigCallback(httpClientBuilder -> httpClientBuilder
                        .setDefaultCredentialsProvider(credentialsProvider))
                .build();

        // Transport 생성
        ElasticsearchTransport transport = new RestClientTransport(
                restClient, new JacksonJsonpMapper());

        return new ElasticsearchClient(transport);
    }
}
```

## 4. 기본 사용 예제

```java
import co.elastic.clients.elasticsearch.ElasticsearchClient;
import co.elastic.clients.elasticsearch.core.IndexResponse;
import co.elastic.clients.elasticsearch.core.SearchResponse;
import co.elastic.clients.elasticsearch.core.search.Hit;

import java.io.IOException;

public class ElasticsearchExample {

    public static void main(String[] args) throws IOException {
        // 클라이언트 생성 (HTTP 버전)
        ElasticsearchClient client = ElasticsearchHTTPClient.createHttpClient();

        // 문서 인덱싱
        Product product = new Product("1", "Laptop", 999.99);
        IndexResponse response = client.index(i -> i
                .index("products")
                .id(product.getId())
                .document(product)
        );

        System.out.println("Indexed document with id: " + response.id());

        // 문서 검색
        SearchResponse<Product> searchResponse = client.search(s -> s
                .index("products")
                .query(q -> q
                        .match(t -> t
                                .field("name")
                                .query("Laptop")
                        )
                ),
                Product.class
        );

        for (Hit<Product> hit : searchResponse.hits().hits()) {
            Product foundProduct = hit.source();
            System.out.println("Found product: " + foundProduct.getName());
        }

        client._transport().close();
    }
}

// 간단한 데이터 클래스
class Product {
    private String id;
    private String name;
    private double price;

    public Product() {}

    public Product(String id, String name, double price) {
        this.id = id;
        this.name = name;
        this.price = price;
    }

    // getters and setters
    public String getId() { return id; }
    public void setId(String id) { this.id = id; }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public double getPrice() { return price; }
    public void setPrice(double price) { this.price = price; }
}
```

## 5. 연결 설정 옵션

```java
import org.apache.http.impl.nio.client.HttpAsyncClientBuilder;
import org.elasticsearch.client.RestClientBuilder;

public class ElasticsearchConfig {

    public static RestClient createCustomRestClient() {
        return RestClient.builder(
                new HttpHost("localhost", 9200, "http"))
                .setRequestConfigCallback(requestConfigBuilder -> requestConfigBuilder
                        .setConnectTimeout(5000)
                        .setSocketTimeout(60000))
                .setHttpClientConfigCallback(httpClientBuilder -> httpClientBuilder
                        .setMaxConnTotal(100)
                        .setMaxConnPerRoute(10))
                .build();
    }
}
```

## 6. 에러 처리

```java
import co.elastic.clients.elasticsearch.ElasticsearchClient;
import co.elastic.clients.elasticsearch._types.ElasticsearchException;

public class ErrorHandlingExample {

    public void handleErrors(ElasticsearchClient client) {
        try {
            // Elasticsearch 작업 수행
            client.index(i -> i.index("test").id("1").document(new Object()));
        } catch (ElasticsearchException e) {
            System.err.println("Elasticsearch error: " + e.getMessage());
            System.err.println("Status code: " + e.status());
        } catch (IOException e) {
            System.err.println("IO error: " + e.getMessage());
        }
    }
}
```

## 주요 주의사항

1. **버전 호환성**: Elasticsearch Java 클라이언트 버전은 Elasticsearch 서버 버전과 일치해야 합니다
2. **연결 종료**: 사용 후 `client._transport().close()`로 연결을 반드시 종료해야 합니다
3. **스레드 안전성**: ElasticsearchClient는 스레드 안전하므로 재사용 가능합니다
4. **인증**: Elasticsearch가 보안 설정되어 있다면 적절한 인증 정보를 제공해야 합니다

이 설정을 통해 Spring 없이도 Java 애플리케이션에서 Elasticsearch 9.x를 효과적으로 사용할 수 있습니다.
