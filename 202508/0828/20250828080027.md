# Spring 없이 Java에서 Elasticsearch 9.x 사용하기 (HTTPS)

Spring 없이 순수 Java로 Elasticsearch 9.x를 HTTPS로 사용하는 방법을 상세히 설명드리겠습니다.

## 1. 의존성 추가

Maven의 경우 `pom.xml`에 다음 의존성을 추가합니다:

```xml
<dependencies>
    <dependency>
        <groupId>org.elasticsearch.client</groupId>
        <artifactId>elasticsearch-rest-client</artifactId>
        <version>9.2.0</version>
    </dependency>
    <dependency>
        <groupId>org.elasticsearch.client</groupId>
        <artifactId>elasticsearch-java</artifactId>
        <version>9.2.0</version>
    </dependency>
    <dependency>
        <groupId>org.apache.httpcomponents.client5</groupId>
        <artifactId>httpclient5</artifactId>
        <version>5.2.1</version>
    </dependency>
</dependencies>
```

Gradle의 경우:
```gradle
dependencies {
    implementation 'org.elasticsearch.client:elasticsearch-rest-client:9.2.0'
    implementation 'org.elasticsearch.client:elasticsearch-java:9.2.0'
    implementation 'org.apache.httpcomponents.client5:httpclient5:5.2.1'
}
```

## 2. SSL/TLS 설정

### 인증서 준비
```java
import org.apache.hc.client5.http.ssl.SSLConnectionSocketFactory;
import org.apache.hc.core5.ssl.SSLContextBuilder;
import javax.net.ssl.SSLContext;
import java.io.InputStream;
import java.nio.file.Files;
import java.nio.file.Paths;
import java.security.KeyStore;

public class ElasticsearchSSLConfig {
    
    public static SSLConnectionSocketFactory createSSLFactory(
            String keystorePath, 
            String keystorePassword,
            String truststorePath,
            String truststorePassword) throws Exception {
        
        // 키스토어 로드
        KeyStore keyStore = KeyStore.getInstance("PKCS12");
        try (InputStream is = Files.newInputStream(Paths.get(keystorePath))) {
            keyStore.load(is, keystorePassword.toCharArray());
        }
        
        // 트러스트스토어 로드
        KeyStore trustStore = KeyStore.getInstance("JKS");
        try (InputStream is = Files.newInputStream(Paths.get(truststorePath))) {
            trustStore.load(is, truststorePassword.toCharArray());
        }
        
        // SSL 컨텍스트 빌드
        SSLContext sslContext = SSLContextBuilder.create()
                .loadKeyMaterial(keyStore, keystorePassword.toCharArray())
                .loadTrustMaterial(trustStore, null)
                .build();
        
        return new SSLConnectionSocketFactory(sslContext);
    }
}
```

## 3. REST 클라이언트 구현

```java
import org.apache.http.HttpHost;
import org.apache.http.auth.AuthScope;
import org.apache.http.auth.UsernamePasswordCredentials;
import org.apache.http.client.CredentialsProvider;
import org.apache.http.impl.client.BasicCredentialsProvider;
import org.apache.http.impl.nio.client.HttpAsyncClientBuilder;
import org.elasticsearch.client.RestClient;
import org.elasticsearch.client.RestClientBuilder;
import org.elasticsearch.client.RestHighLevelClient;

import java.io.IOException;

public class ElasticsearchClientManager {
    
    private RestHighLevelClient client;
    
    public ElasticsearchClientManager(String host, int port, String scheme,
                                    String username, String password,
                                    SSLConnectionSocketFactory sslFactory) {
        
        // 인증 정보 설정
        final CredentialsProvider credentialsProvider = new BasicCredentialsProvider();
        credentialsProvider.setCredentials(
            AuthScope.ANY,
            new UsernamePasswordCredentials(username, password)
        );
        
        // REST 클라이언트 빌더 생성
        RestClientBuilder builder = RestClient.builder(
            new HttpHost(host, port, scheme)
        );
        
        // HTTP 클라이언트 설정
        builder.setHttpClientConfigCallback(new RestClientBuilder.HttpClientConfigCallback() {
            @Override
            public HttpAsyncClientBuilder customizeHttpClient(HttpAsyncClientBuilder httpClientBuilder) {
                return httpClientBuilder
                    .setDefaultCredentialsProvider(credentialsProvider)
                    .setSSLStrategy(sslFactory);
            }
        });
        
        this.client = new RestHighLevelClient(builder);
    }
    
    public RestHighLevelClient getClient() {
        return client;
    }
    
    public void close() throws IOException {
        if (client != null) {
            client.close();
        }
    }
}
```

## 4. Java API 클라이언트 구현 (Elasticsearch 8.x+ 권장)

```java
import co.elastic.clients.elasticsearch.ElasticsearchClient;
import co.elastic.clients.elasticsearch._types.ElasticsearchException;
import co.elastic.clients.elasticsearch.core.IndexRequest;
import co.elastic.clients.elasticsearch.core.IndexResponse;
import co.elastic.clients.json.jackson.JacksonJsonpMapper;
import co.elastic.clients.transport.ElasticsearchTransport;
import co.elastic.clients.transport.rest_client.RestClientTransport;
import org.apache.http.HttpHost;
import org.apache.http.auth.AuthScope;
import org.apache.http.auth.UsernamePasswordCredentials;
import org.apache.http.client.CredentialsProvider;
import org.apache.http.impl.client.BasicCredentialsProvider;
import org.apache.http.impl.nio.client.HttpAsyncClientBuilder;
import org.elasticsearch.client.RestClient;

import java.io.IOException;

public class ElasticsearchJavaClient {
    
    private ElasticsearchClient client;
    
    public ElasticsearchJavaClient(String host, int port, String username, String password) {
        
        // 인증 정보 설정
        final CredentialsProvider credentialsProvider = new BasicCredentialsProvider();
        credentialsProvider.setCredentials(
            AuthScope.ANY,
            new UsernamePasswordCredentials(username, password)
        );
        
        // REST 클라이언트 생성
        RestClient restClient = RestClient.builder(
            new HttpHost(host, port, "https")
        ).setHttpClientConfigCallback(new RestClientBuilder.HttpClientConfigCallback() {
            @Override
            public HttpAsyncClientBuilder customizeHttpClient(HttpAsyncClientBuilder httpClientBuilder) {
                return httpClientBuilder.setDefaultCredentialsProvider(credentialsProvider);
            }
        }).build();
        
        // Transport와 JSON 매퍼 생성
        ElasticsearchTransport transport = new RestClientTransport(
            restClient, new JacksonJsonpMapper()
        );
        
        // Java API 클라이언트 생성
        this.client = new ElasticsearchClient(transport);
    }
    
    public ElasticsearchClient getClient() {
        return client;
    }
    
    // 문서 인덱싱 예제
    public String indexDocument(String indexName, Object document) throws IOException {
        IndexRequest<Object> request = IndexRequest.of(b -> b
            .index(indexName)
            .document(document)
        );
        
        IndexResponse response = client.index(request);
        return response.id();
    }
    
    public void close() throws IOException {
        if (client != null) {
            client._transport().close();
        }
    }
}
```

## 5. 사용 예제

```java
public class ElasticsearchExample {
    
    public static void main(String[] args) {
        try {
            // SSL 팩토리 생성
            SSLConnectionSocketFactory sslFactory = ElasticsearchSSLConfig.createSSLFactory(
                "path/to/keystore.p12", "keystore-password",
                "path/to/truststore.jks", "truststore-password"
            );
            
            // 클라이언트 생성
            ElasticsearchJavaClient esClient = new ElasticsearchJavaClient(
                "your-elasticsearch-host", 
                9200, 
                "username", 
                "password"
            );
            
            // 문서 인덱싱
            Map<String, Object> document = new HashMap<>();
            document.put("title", "Test Document");
            document.put("content", "This is a test document");
            document.put("timestamp", new Date());
            
            String documentId = esClient.indexDocument("test-index", document);
            System.out.println("Document indexed with ID: " + documentId);
            
            // 클라이언트 종료
            esClient.close();
            
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

## 주의사항

1. **Elasticsearch 8.x+에서는 Java API 클라이언트 사용을 권장**합니다.
2. **SSL 인증서는 반드시 신뢰할 수 있는 CA에서 발급**받아야 합니다.
3. **연결 풀링과 적절한 타임아웃 설정**이 중요합니다.
4. **리소스 누수를 방지하기 위해 사용 후 반드시 close() 호출**해야 합니다.
5. **프로덕션 환경에서는 설정을 외부화**하는 것이 좋습니다.

이렇게 구성하면 Spring 없이도 Elasticsearch 9.x와 안전한 HTTPS 통신을 할 수 있습니다.
