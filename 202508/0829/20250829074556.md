## 📌 주요 Object Mapper 라이브러리별 현황

### 1. **Jackson** (가장 널리 사용됨)
가장 인기 있는 JSON 처리 라이브러리로, Spring Framework의 기본 매퍼입니다.

| Java 버전 | 마지막 안정적 버전 | 주요 특징 |
|-----------|-------------------|-----------|
| **Java 8+** | **2.16.1** (최신) | • 최신 기능 및 보안 패치 포함<br>• 모듈식 구조<br>• 최적의 성능 |
| **Java 7** | 2.12.7 | • Java 7 호환 마지막 버전<br>• LTS(장기 지원) |
| **Java 6** | 2.10.5 | • 레거시 시스템용<br>• 보안 업데이트 중단 |

**의존성 추가 (Maven - Java 8+):**
```xml
<dependency>
    <groupId>com.fasterxml.jackson.core</groupId>
    <artifactId>jackson-databind</artifactId>
    <version>2.16.1</version>
</dependency>
```

| Java 버전 | 마지막 안정적 버전 | 주요 특징 |
|-----------|-------------------|-----------|
| **Java 8+** | **2.10.1** (최신) | • 최신 기능 지원<br>• 향상된 성능 |
| **Java 7** | 2.8.9 | • Java 7 호환 |
| **Java 6** | 2.8.6 | • 레거시 지원 |

**의존성 추가:**
```xml

    <groupId>com.google.code.gson</groupId>
    <artifactId>gson</artifactId>
    <version>2.10.1</version>
</dependency>
```

### 3. **MapStruct** (코드 생성 방식)
컴파일 타임 코드 생성을 통한 고성능 매퍼

| Java 버전 | 마지막 안정적 버전 | 주요 특징 |
|-----------|-------------------|-----------|
| **Java 8+** | **1.5.5.Final** | • 최적의 런타임 성능<br>• 컴파일 타임 안정성 |
| **Java 7** | 1.3.1.Final | • Java 7 호환 마지막 버전 |

**의존성 추가:**
```xml
<dependency>
    <groupId>org.mapstruct</groupId>
    <artifactId>mapstruct</artifactId>
    <version>1.5.5.Final</version>
</dependency>
```

## ⚠️ 중요 고려사항

1. **보안**: 최신 버전은 보안 취약점이 수정되어 있습니다
2. **성능**: 새로운 버전일수록 일반적으로 성능이 улуч됩니다
3. **호환성**: 기존 코드와의 호환성을 반드시 확인하세요
4. **Spring 연동**: Spring 사용 시 Jackson이 가장 원활하게 연동됩니다
