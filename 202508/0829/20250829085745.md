# ObjectMapper 객체 요소 명 변경하지 않는 방법

ObjectMapper에서 객체 요소(필드) 이름을 변경하지 않고 그대로 유지하는 방법에 대해 상세히 설명드리겠습니다.

## 기본 동작

Jackson ObjectMapper는 기본적으로 Java 객체의 필드 이름을 JSON 속성 이름으로 그대로 사용합니다. 따라서 특별한 설정을 하지 않으면 필드 이름이 변경되지 않습니다.

```java
public class User {
    private String userName;  // JSON에서는 "userName"으로 매핑됨
    private int userAge;      // JSON에서는 "userAge"로 매핑됨
    
    // getters, setters
}

ObjectMapper mapper = new ObjectMapper();
User user = new User("John", 30);
String json = mapper.writeValueAsString(user);
// 결과: {"userName":"John","userAge":30}
```

## 명시적으로 변경 방지 설정

### 1. @JsonAutoDetect 어노테이션 사용

```java
@JsonAutoDetect(
    fieldVisibility = JsonAutoDetect.Visibility.ANY,
    getterVisibility = JsonAutoDetect.Visibility.NONE,
    setterVisibility = JsonAutoDetect.Visibility.NONE
)
public class User {
    private String userName;
    private int userAge;
    
    // getters, setters
}
```

### 2. Mapper 설정 변경

```java
ObjectMapper mapper = new ObjectMapper();

// 속성 이름 변경 방지 설정
mapper.setPropertyNamingStrategy(PropertyNamingStrategies.LOWER_CAMEL_CASE);
mapper.configure(MapperFeature.USE_STD_BEAN_NAMING, true);
mapper.setVisibility(PropertyAccessor.FIELD, JsonAutoDetect.Visibility.ANY);
mapper.setVisibility(PropertyAccessor.GETTER, JsonAutoDetect.Visibility.NONE);
mapper.setVisibility(PropertyAccessor.SETTER, JsonAutoDetect.Visibility.NONE);
```

### 3. @JsonProperty 어노테이션으로 명시적 유지

```java
public class User {
    @JsonProperty("userName") // 원하는 이름으로 명시적으로 지정
    private String userName;
    
    @JsonProperty("userAge")  // 원하는 이름으로 명시적으로 지정
    private int userAge;
    
    // getters, setters
}
```

## 전체 예제 코드

```java
import com.fasterxml.jackson.annotation.JsonAutoDetect;
import com.fasterxml.jackson.annotation.JsonProperty;
import com.fasterxml.jackson.databind.ObjectMapper;
import com.fasterxml.jackson.databind.PropertyNamingStrategies;

public class ObjectMapperExample {
    
    // 필드 이름 변경 없이 사용할 클래스
    public static class User {
        private String userName;
        private int userAge;
        
        public User() {}
        
        public User(String userName, int userAge) {
            this.userName = userName;
            this.userAge = userAge;
        }
        
        // getters and setters
        public String getUserName() { return userName; }
        public void setUserName(String userName) { this.userName = userName; }
        public int getUserAge() { return userAge; }
        public void setUserAge(int userAge) { this.userAge = userAge; }
    }
    
    public static void main(String[] args) throws Exception {
        ObjectMapper mapper = new ObjectMapper();
        
        // 객체 생성
        User user = new User("JohnDoe", 25);
        
        // JSON으로 변환 (필드 이름 변경 없음)
        String json = mapper.writeValueAsString(user);
        System.out.println("JSON: " + json);
        // 출력: {"userName":"JohnDoe","userAge":25}
        
        // JSON에서 객체로 변환
        User parsedUser = mapper.readValue(json, User.class);
        System.out.println("Parsed User: " + parsedUser.getUserName() + ", " + parsedUser.getUserAge());
    }
}
```

## 주의사항

1. **Lombok 사용 시**: Lombok의 @Getter, @Setter가 생성하는 메서드 이름에 주의
2. **Boolean 필드**: is 접두사가 있는 boolean 필드는 특별한 규칙 적용
3. **직렬화/역직렬화 정책**: 필요에 따라 다른 정책을 적용할 수 있음

기본적으로 ObjectMapper는 필드 이름을 변경하지 않으므로, 특별한 naming strategy를 설정하지 않았다면 필드 이름이 그대로 유지됩니다.
