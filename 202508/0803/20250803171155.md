# 엘라스틱서치(Elasticsearch) 기본 명령어 및 LIKE 조건 조회 방법

엘라스틱서치에서 데이터를 조회할 때 사용하는 기본 명령어와 SQL의 LIKE 조건에 해당하는 검색 방법을 설명드리겠습니다.

## 기본 명령어

### 1. 인덱스 조회
```bash
# 모든 인덱스 조회
GET /_cat/indices?v

# 특정 인덱스 정보 조회
GET /인덱스명
```

### 2. 도큐먼트 조회
```bash
# 인덱스 내 모든 도큐먼트 조회
GET /인덱스명/_search
{
  "query": {
    "match_all": {}
  }
}

# 특정 도큐먼트 조회 (ID로)
GET /인덱스명/_doc/도큐먼트ID
```

### 3. 매핑 정보 조회
```bash
GET /인덱스명/_mapping
```

## LIKE 조건에 해당하는 검색 방법

### 1. Wildcard Query (와일드카드 검색)
```bash
GET /인덱스명/_search
{
  "query": {
    "wildcard": {
      "필드명": {
        "value": "*검색어*"  # 앞뒤로 *를 사용하여 LIKE '%검색어%' 구현
      }
    }
  }
}
```

### 2. Query String Query (유사도 검색)
```bash
GET /인덱스명/_search
{
  "query": {
    "query_string": {
      "default_field": "필드명",
      "query": "*검색어*"
    }
  }
}
```

### 3. Match Query (부분 일치 검색)
```bash
GET /인덱스명/_search
{
  "query": {
    "match": {
      "필드명": "검색어"
    }
  }
}
```

### 4. Regexp Query (정규식 검색)
```bash
GET /인덱스명/_search
{
  "query": {
    "regexp": {
      "필드명": {
        "value": ".*검색어.*",
        "flags": "ALL"
      }
    }
  }
}
```

### 5. N-gram 또는 Edge-ngram 토큰 필터 사용
매핑 설정 시 n-gram 토크나이저를 사용하면 더 효과적인 부분 일치 검색이 가능합니다.

## 기타 유용한 검색 옵션

### 페이징 처리
```bash
GET /인덱스명/_search
{
  "from": 0,
  "size": 10,
  "query": {
    "match_all": {}
  }
}
```

### 정렬
```bash
GET /인덱스명/_search
{
  "sort": [
    {
      "필드명": {
        "order": "asc"
      }
    }
  ],
  "query": {
    "match_all": {}
  }
}
```

### 특정 필드만 조회
```bash
GET /인덱스명/_search
{
  "_source": ["필드1", "필드2"],
  "query": {
    "match_all": {}
  }
}
```

엘라스틱서치 버전에 따라 일부 쿼리 문법이 다를 수 있으니, 사용 중인 버전의 공식 문서를 참조하는 것이 좋습니다. 특히 LIKE 조건에 해당하는 검색은 성능에 영향을 줄 수 있으므로, 필요한 경우 적절한 분석기와 토크나이저 설정을 고려해야 합니다.
