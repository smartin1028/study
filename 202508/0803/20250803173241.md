Elasticsearch 7.10 버전부터는 기본적인 보안 기능이 활성화되어 있으며, 기본 인증 정보(username/password)가 제공됩니다. 다음은 기본 계정 정보입니다:

### 기본 인증 정보
- **Username**: `elastic`  
- **Password**: Elasticsearch를 처음 실행할 때 자동 생성되며, 터미널 출력 또는 로그 파일에서 확인할 수 있습니다.

### 비밀번호 확인 방법
1. **터�미널 출력 확인**:  
   Elasticsearch를 시작할 때 터미널에 다음과 같은 메시지가 출력됩니다:  
   ```plaintext
   Password for the elastic user (reset with `bin/elasticsearch-reset-password -u elastic`):
   xxxxxxxx
   ```

2. **로그 파일 확인**:  
   로그 파일(`logs/elasticsearch.log`)에서도 비밀번호를 찾을 수 있습니다.  
   ```plaintext
   grep "Password for the elastic" /path/to/elasticsearch/logs/elasticsearch.log
   ```

3. **비밀번호 재설정**:  
   비밀번호를 분실한 경우 다음 명령어로 재설정할 수 있습니다:  
   ```bash
   bin/elasticsearch-reset-password -u elastic
   ```

### 추가 정보
- **기본 계정 역할**:  
  `elastic` 사용자는 `superuser` 역할을 가지며, 모든 권한을 보유합니다.  
- **다른 기본 계정**:  
  `kibana_system`, `logstash_system`, `beats_system` 등의 시스템 계정도 자동 생성됩니다.  

### 주의 사항
- Elasticsearch 6.x 이전 버전은 기본 보안 기능이 비활성화되어 있습니다.  
- 프로덕션 환경에서는 반드시 기본 비밀번호를 변경하고, TLS/SSL을 구성하는 것이 권장됩니다.
