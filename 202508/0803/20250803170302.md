# 엘라스틱서치(Elasticsearch) 기본 명령어 가이드

엘라스틱서치를 사용하기 위한 기본적인 명령어와 REST API 사용법을 설명드리겠습니다. 대부분의 명령은 HTTP 요청을 통해 실행됩니다.

## 1. 클러스터 상태 확인

### 클러스터 건강 상태 확인
```bash
GET /_cluster/health
```
- `green`: 모든 샤드가 정상
- `yellow`: 모든 기본 샤드는 정상이지만 레플리카 샤드 일부가 없음
- `red`: 일부 기본 샤드가 없음

### 노드 정보 확인
```bash
GET /_cat/nodes?v
```

## 2. 인덱스 관리

### 인덱스 생성
```bash
PUT /인덱스명
{
  "settings": {
    "number_of_shards": 3,
    "number_of_replicas": 1
  }
}
```

### 인덱스 목록 확인
```bash
GET /_cat/indices?v
```

### 인덱스 삭제
```bash
DELETE /인덱스명
```

### 인덱스 매핑 확인
```bash
GET /인덱스명/_mapping
```

## 3. 문서(도큐먼트) 작업

### 문서 생성/업데이트
```bash
PUT /인덱스명/_doc/문서ID
{
  "field1": "value1",
  "field2": "value2"
}
```

### 문서 조회
```bash
GET /인덱스명/_doc/문서ID
```

### 문서 삭제
```bash
DELETE /인덱스명/_doc/문서ID
```

### 문서 일괄 처리 (Bulk API)
```bash
POST /_bulk
{ "index" : { "_index" : "인덱스명", "_id" : "1" } }
{ "field1" : "value1" }
{ "delete" : { "_index" : "인덱스명", "_id" : "2" } }
{ "create" : { "_index" : "인덱스명", "_id" : "3" } }
{ "field1" : "value3" }
{ "update" : {"_id" : "1", "_index" : "인덱스명"} }
{ "doc" : {"field2" : "value2"} }
```

## 4. 검색

### 전체 검색
```bash
GET /인덱스명/_search
```

### 쿼리 검색
```bash
GET /인덱스명/_search
{
  "query": {
    "match": {
      "field1": "검색어"
    }
  }
}
```

### 집계(Aggregation) 검색
```bash
GET /인덱스명/_search
{
  "aggs": {
    "이름": {
      "terms": { "field": "필드명" }
    }
  }
}
```

## 5. 설정 관리

### 클러스터 설정 확인
```bash
GET /_cluster/settings
```

### 인덱스 설정 변경
```bash
PUT /인덱스명/_settings
{
  "index": {
    "number_of_replicas": 2
  }
}
```

## 6. 유용한 _cat API 명령어

### 샤드 할당 확인
```bash
GET /_cat/shards?v
```

### 템플릿 목록 확인
```bash
GET /_cat/templates?v
```

### 플러그인 목록 확인
```bash
GET /_cat/plugins?v
```

## 7. 기타 유용한 명령어

### 스냅샷 저장소 등록
```bash
PUT /_snapshot/저장소명
{
  "type": "fs",
  "settings": {
    "location": "/path/to/snapshots"
  }
}
```

### 스냅샷 생성
```bash
PUT /_snapshot/저장소명/스냅샷명?wait_for_completion=true
```

이 명령어들은 엘라스틱서치를 운영하고 데이터를 관리하는 데 기본적으로 필요한 것들입니다. 실제 사용 시에는 각 명령에 필요한 파라미터를 추가하거나 응답을 분석하여 사용하시면 됩니다.
