# Elasticsearch-setup-passwords 사용법 상세 설명

`elasticsearch-setup-passwords`는 Elasticsearch에서 기본 보안 기능을 설정하기 위한 유틸리티로, 내장된 사용자 계정들의 비밀번호를 초기화하거나 변경하는 데 사용됩니다.

## 기본 사용법

```bash
bin/elasticsearch-setup-passwords [options]
```

## 주요 옵션

1. **auto (자동 모드)**
   ```bash
   bin/elasticsearch-setup-passwords auto
   ```
   - 모든 내장 사용자(elastic, kibana, logstash_system 등)에 대해 자동으로 랜덤 비밀번호 생성
   - 생성된 비밀번호는 터미널에 출력되므로 반드시 저장 필요
   - 프로덕션 환경에서 권장되는 방법

2. **interactive (대화형 모드)**
   ```bash
   bin/elasticsearch-setup-passwords interactive
   ```
   - 각 내장 사용자별로 비밀번호를 수동으로 입력
   - 사용자와 상호작용하며 비밀번호 설정

3. **URL 지정**
   ```bash
   bin/elasticsearch-setup-passwords auto -u "http://localhost:9200"
   ```
   - 기본 URL이 아닌 다른 주소로 연결할 때 사용

## 실행 전 준비사항

1. Elasticsearch가 실행 중이어야 함
2. `xpack.security.enabled: true` 설정이 되어 있어야 함
3. 최초 1회만 실행 가능 (재실행 시 오류 발생)

## 실행 후 확인

```bash
curl -u elastic -XGET 'http://localhost:9200/_security/user'
```

## 주의사항

1. **비밀번호 저장 필수**: auto 모드로 생성된 비밀번호는 다시 확인할 수 없으므로 반드시 저장
2. **한 번만 실행**: 이미 비밀번호가 설정된 상태에서 재실행하면 오류 발생
3. **Kibana 연동**: kibana_system 사용자 비밀번호는 Kibana 설정 파일에 반영 필요
4. **네트워크 보안**: 기본적으로 localhost에서만 실행 가능, 원격에서 실행하려면 추가 설정 필요

## 비밀번호 초기화 방법

이미 설정된 비밀번호를 잊어버린 경우:
1. Elasticsearch 정지
2. 설정 파일에 `xpack.security.authc.accept_default_password: true` 추가
3. Elasticsearch 재시작
4. `elasticsearch-reset-password` 툴 사용하여 비밀번호 재설정

이 명령어는 Elasticsearch 보안 설정의 첫 단계로, 반드시 안전하게 비밀번호를 관리해야 합니다.
