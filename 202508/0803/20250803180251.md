Elasticsearch 7.10 버전에서 Python 클라이언트를 사용하여 로그인(인증)을 하는 방식은 주로 **`elasticsearch-py`** 공식 라이브러리를 통해 지원됩니다. 아래에 자세한 방법을 설명드리겠습니다.

---

### **1. 기본 인증 (Basic Authentication)**
가장 일반적인 방식으로, 사용자 이름과 비밀번호를 이용한 HTTP 기본 인증입니다.

```python
from elasticsearch import Elasticsearch

# 기본 인증 사용
es = Elasticsearch(
    ["http://localhost:9200"],  # Elasticsearch 서버 주소
    http_auth=("username", "password"),  # 인증 정보
    verify_certs=True  # SSL 인증서 검증 (옵션)
)

# 테스트 연결
print(es.info())
```

---

### **2. API 키 인증 (API Key Authentication)**
Elasticsearch 7.x부터 지원되는 API 키를 이용한 인증 방식입니다.

```python
from elasticsearch import Elasticsearch

# API 키 인증
es = Elasticsearch(
    ["http://localhost:9200"],
    api_key=("api_key_id", "api_key_secret")  # (ID, Secret) 형식
)

# 예시: API 키 생성 (Elasticsearch에서 먼저 생성 필요)
# POST /_security/api_key
# {
#   "name": "my-api-key"
# }
```

---

### **3. SSL/TLS 인증 (HTTPS + 클라이언트 인증서)**
SSL/TLS를 통한 보안 연결 시 클라이언트 인증서를 사용할 수 있습니다.

```python
from elasticsearch import Elasticsearch

# SSL/TLS 인증
es = Elasticsearch(
    ["https://localhost:9200"],
    http_auth=("username", "password"),
    ca_certs="/path/to/ca_cert.pem",  # CA 인증서 경로
    client_cert="/path/to/client_cert.pem",  # 클라이언트 인증서
    client_key="/path/to/client_key.pem"  # 클라이언트 키
)
```

---

### **4. Elastic Cloud (Elasticsearch Service) 인증**
Elastic Cloud를 사용하는 경우, `Cloud ID`와 API 키를 이용한 인증이 가능합니다.

```python
from elasticsearch import Elasticsearch

# Elastic Cloud 인증
es = Elasticsearch(
    cloud_id="your-cloud-id",  # Elastic Cloud에서 제공하는 Cloud ID
    api_key=("api_key_id", "api_key_secret")
)
```

---

### **5. Kerberos 인증**
엔터프라이즈 환경에서 Kerberos 인증을 사용하는 경우:

```python
from elasticsearch import Elasticsearch
from requests_kerberos import HTTPKerberosAuth

# Kerberos 인증
es = Elasticsearch(
    ["http://localhost:9200"],
    http_auth=HTTPKerberosAuth()
)
```

> ⚠️ `requests-kerberos` 패키지가 필요:  
> `pip install requests-kerberos`

---

### **주의사항**
1. **버전 호환성**:  
   - Elasticsearch 7.10은 `elasticsearch-py` 7.x 버전과 호환됩니다.  
     ```bash
     pip install elasticsearch==7.10.1
     ```
2. **보안 설정**:  
   - 인증 없이 접근하려면 Elasticsearch의 `elasticsearch.yml`에서 `xpack.security.enabled: false`로 설정해야 합니다 (비추천).

3. **인증 실패 시**:  
   - `AuthenticationException`이 발생하면 인증 정보 또는 네트워크 설정을 확인하세요.
