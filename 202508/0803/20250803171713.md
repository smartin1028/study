# 엘라스틱서치 기본 명령어 및 Pandas 연동 방법

## 엘라스틱서치 기본 검색 명령어

### 1. 기본 검색 (Match Query)
```json
GET /인덱스명/_search
{
  "query": {
    "match": {
      "필드명": "검색어"
    }
  }
}
```

### 2. AND 조건 검색 (Bool + Must)
```json
GET /인덱스명/_search
{
  "query": {
    "bool": {
      "must": [
        { "match": { "필드1": "값1" } },
        { "match": { "필드2": "값2" } }
      ]
    }
  }
}
```

### 3. OR 조건 검색 (Bool + Should)
```json
GET /인덱스명/_search
{
  "query": {
    "bool": {
      "should": [
        { "match": { "필드1": "값1" } },
        { "match": { "필드2": "값2" } }
      ],
      "minimum_should_match": 1
    }
  }
}
```

### 4. NOT 조건 검색 (Bool + Must Not)
```json
GET /인덱스명/_search
{
  "query": {
    "bool": {
      "must_not": [
        { "match": { "필드명": "제외할값" } }
      ]
    }
  }
}
```

### 5. 범위 검색 (Range Query)
```json
GET /인덱스명/_search
{
  "query": {
    "range": {
      "날짜필드": {
        "gte": "2023-01-01",
        "lte": "2023-12-31"
      }
    }
  }
}
```

### 6. 정렬 (Sort)
```json
GET /인덱스명/_search
{
  "sort": [
    { "필드명": { "order": "asc" } }
  ]
}
```

## Pandas로 결과 처리하기

### 1. 엘라스틱서치 결과를 Pandas DataFrame으로 변환

```python
from elasticsearch import Elasticsearch
import pandas as pd

# Elasticsearch 연결
es = Elasticsearch(["http://localhost:9200"])

# 검색 실행
response = es.search(
    index="인덱스명",
    body={
        "query": {
            "match_all": {}
        },
        "size": 10000  # 가져올 문서 수
    }
)

# 결과를 DataFrame으로 변환
hits = response['hits']['hits']
df = pd.DataFrame([hit['_source'] for hit in hits])

# 결과 확인
print(df.head())
```

### 2. 고급 Pandas 처리 예제

```python
# 필요한 컬럼만 선택
df = df[['field1', 'field2', 'field3']]

# 결측치 처리
df = df.fillna('N/A')

# 날짜 형식 변환
df['date_field'] = pd.to_datetime(df['date_field'])

# 그룹별 집계
grouped = df.groupby('category_field').agg({
    'numeric_field': ['mean', 'sum', 'count']
})

# 조건 필터링
filtered_df = df[df['numeric_field'] > 100]

# 정렬
sorted_df = df.sort_values(by='date_field', ascending=False)
```

### 3. 시각화 예제

```python
import matplotlib.pyplot as plt

# 기본 통계 시각화
df['numeric_field'].hist(bins=20)
plt.title('Distribution of Numeric Field')
plt.show()

# 그룹별 비교
df.groupby('category_field')['numeric_field'].mean().plot(kind='bar')
plt.title('Average by Category')
plt.show()
```

### 4. 대용량 데이터 처리 팁

```python
# Scroll API 사용 (대량 데이터 처리)
from elasticsearch.helpers import scan

query = {"query": {"match_all": {}}}
results = scan(es, query=query, index="인덱스명", size=1000)

# 제너레이터에서 DataFrame 생성
df = pd.DataFrame([hit['_source'] for hit in results])
```

이렇게 엘라스틱서치 쿼리 결과를 Pandas DataFrame으로 변환하면 데이터 분석, 시각화, 추가 처리 등이 매우 편리해집니다. 특히 대용량 데이터를 다룰 때는 Scroll API를 활용하는 것이 좋습니다.
