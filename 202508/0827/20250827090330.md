# 윈도우 CMD 작업을 서비스로 등록하는 방법

CMD로 수행하는 작업을 Windows 서비스로 등록하면 시스템 부팅 시 자동으로 실행되고, 백그라운드에서 지속적으로 실행되며, 서비스 관리자를 통해 관리할 수 있는 장점이 있습니다.

## 주요 방법

### 1. NSSM (Non-Sucking Service Manager) 사용

NSSM은 가장 간단하고 효과적인 방법입니다.

#### 설치 및 사용법

1. **NSSM 다운로드**
   - 공식 사이트(https://nssm.cc)에서 다운로드
   - 32비트/64비트에 맞는 버전 선택

2. **서비스 등록**
   ```cmd
   # cmd 창을 관리자 권한으로 실행
   nssm install [서비스이름]
   ```
   
3. **설정 구성**
   - Application 탭: 실행할 프로그램 경로 지정 (cmd.exe)
   - Arguments: `/c "실행할 명령어"`
   - Details 탭: 서비스 이름, 설명 설정
   - Log on 탭: 실행 계정 설정

4. **서비스 관리**
   ```cmd
   # 서비스 시작
   nssm start [서비스이름]
   
   # 서비스 중지
   nssm stop [서비스이름]
   
   # 서비스 삭제
   nssm remove [서비스이름]
   ```

### 2. SC (Service Control) 명령어 사용

Windows 기본 제공 도구를 이용하는 방법입니다.

```cmd
# 서비스 생성
sc create MyService binPath= "cmd /c start [실행할 명령어]" type= own start= auto

# 서비스 시작
sc start MyService

# 서비스 중지
sc stop MyService

# 서비스 삭제
sc delete MyService
```

### 3. PowerShell 사용

```powershell
# 서비스 생성
New-Service -Name "MyService" -BinaryPathName "cmd /c [실행할 명령어]" -StartupType Automatic

# 서비스 시작
Start-Service -Name "MyService"

# 서비스 중지
Stop-Service -Name "MyService"

# 서비스 삭제
Remove-Service -Name "MyService"
```

## 실제 예제: Python 스크립트 서비스 등록

```cmd
# NSSM을 이용한 Python 스크립트 서비스 등록
nssm install MyPythonService
# 경로: C:\Python39\python.exe
# 인수: C:\scripts\myscript.py
```

## 주의사항

1. **관리자 권한**: 서비스 등록/삭제는 관리자 권한이 필요합니다
2. **경로 문제**: 절대 경로를 사용하는 것이 안전합니다
3. **로그 확인**: 서비스 실행 로그를 꼭 확인하세요
4. **의존성**: 서비스가 의존하는 다른 서비스가 있는지 확인

## 문제 해결

- **서비스 시작 실패**: 이벤트 뷰어에서 로그 확인
- **권한 문제**: 적절한 계정으로 실행 권한 부여
- **경로 문제**: 공백이 있는 경로는 따옴표로 감싸기

NSSM이 사용하기 가장 쉽고 강력한 기능을 제공하므로初学者에게 추천합니다. SC 명령어는 기본 제공되지만 설정이 복잡할 수 있습니다.
