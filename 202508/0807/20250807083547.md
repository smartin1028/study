# Java List<Map>을 Tablesaw로 변환하는 방법

Java에서 `List<Map>` 형태의 데이터를 Tablesaw 라이브러리로 변환하는 방법을 단계별로 설명드리겠습니다.

## 기본 변환 방법

```java
import tech.tablesaw.api.Table;
import java.util.List;
import java.util.Map;

public class ListMapToTablesaw {
    public static Table convert(List<Map<String, Object>> data) {
        // 빈 테이블 생성
        Table table = Table.create();
        
        // 첫 번째 맵에서 컬럼 이름 추출 (모든 맵이 동일한 구조라고 가정)
        if (!data.isEmpty()) {
            Map<String, Object> firstRow = data.get(0);
            
            // 각 컬럼 생성 및 추가
            for (String columnName : firstRow.keySet()) {
                Object sampleValue = firstRow.get(columnName);
                
                // 값의 타입에 따라 적절한 컬럼 생성
                if (sampleValue instanceof Number) {
                    table.addColumns(DoubleColumn.create(columnName));
                } else if (sampleValue instanceof String) {
                    table.addColumns(StringColumn.create(columnName));
                } else if (sampleValue instanceof Boolean) {
                    table.addColumns(BooleanColumn.create(columnName));
                }
                // 다른 타입들도 필요에 따라 추가
            }
            
            // 데이터 추가
            for (Map<String, Object> row : data) {
                for (String columnName : row.keySet()) {
                    Object value = row.get(columnName);
                    table.column(columnName).append(value);
                }
            }
        }
        
        return table;
    }
}
```

## 더 효율적인 방법 (컬럼별 데이터 수집)

```java
import tech.tablesaw.api.*;
import java.util.*;

public class ListMapToTablesaw {
    public static Table convert(List<Map<String, Object>> data) {
        if (data.isEmpty()) {
            return Table.create();
        }
        
        // 컬럼 이름 추출
        Set<String> columnNames = data.get(0).keySet();
        
        // 컬럼별 데이터 수집
        Map<String, List<Object>> columnData = new HashMap<>();
        for (String colName : columnNames) {
            columnData.put(colName, new ArrayList<>());
        }
        
        for (Map<String, Object> row : data) {
            for (String colName : columnNames) {
                columnData.get(colName).add(row.get(colName));
            }
        }
        
        // 테이블 생성
        Table table = Table.create();
        
        for (String colName : columnNames) {
            List<Object> values = columnData.get(colName);
            if (!values.isEmpty()) {
                Object firstValue = values.get(0);
                
                if (firstValue instanceof Number) {
                    DoubleColumn col = DoubleColumn.create(colName);
                    for (Object value : values) {
                        col.append(value == null ? Double.NaN : ((Number) value).doubleValue());
                    }
                    table.addColumns(col);
                } else if (firstValue instanceof String) {
                    StringColumn col = StringColumn.create(colName);
                    for (Object value : values) {
                        col.append(value == null ? "" : value.toString());
                    }
                    table.addColumns(col);
                }
                // 다른 타입들도 필요에 따라 추가
            }
        }
        
        return table;
    }
}
```

## 사용 예시

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        List<Map<String, Object>> data = new ArrayList<>();
        
        Map<String, Object> row1 = new HashMap<>();
        row1.put("Name", "John");
        row1.put("Age", 30);
        row1.put("Salary", 50000.0);
        
        Map<String, Object> row2 = new HashMap<>();
        row2.put("Name", "Jane");
        row2.put("Age", 25);
        row2.put("Salary", 60000.0);
        
        data.add(row1);
        data.add(row2);
        
        Table table = ListMapToTablesaw.convert(data);
        System.out.println(table.print());
    }
}
```

## 주의사항

1. **데이터 타입 처리**: 모든 값이 동일한 타입이라고 가정하지 말고, 실제 데이터 타입을 확인해야 합니다.
2. **null 값 처리**: null 값에 대한 적절한 처리가 필요합니다.
3. **대용량 데이터**: 대용량 데이터의 경우 성능을 고려하여 최적화가 필요할 수 있습니다.
4. **컬럼 순서**: Map은 순서를 보장하지 않으므로 컬럼 순서가 중요하다면 LinkedHashMap을 사용하거나 별도로 순서를 관리해야 합니다.

이 코드를 기반으로 실제 사용 환경에 맞게 수정하여 사용하시면 됩니다.
