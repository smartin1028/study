# TimeLeaf 화면에서 2개 입력을 그리드로 표시하는 화면 구현

TimeLeaf(타임리프, Thymeleaf)를 사용하여 2개의 입력을 받고 그 결과를 그리드 형태로 표시하는 화면을 구현하는 방법을 설명드리겠습니다.

## 기본 구현 코드

### 1. Controller (컨트롤러)

```java
@Controller
public class GridController {
    
    @GetMapping("/grid-input")
    public String showInputForm(Model model) {
        model.addAttribute("inputForm", new InputForm());
        return "grid-input";
    }
    
    @PostMapping("/process-grid")
    public String processInput(@ModelAttribute InputForm inputForm, Model model) {
        // 입력 처리 로직 (필요시 추가)
        model.addAttribute("input1", inputForm.getInput1());
        model.addAttribute("input2", inputForm.getInput2());
        return "grid-result";
    }
}

// 입력 폼 데이터를 담을 DTO
public class InputForm {
    private String input1;
    private String input2;
    
    // getters and setters
    public String getInput1() { return input1; }
    public void setInput1(String input1) { this.input1 = input1; }
    public String getInput2() { return input2; }
    public void setInput2(String input2) { this.input2 = input2; }
}
```

## 고급 구현 (동적 그리드)

여러 개의 입력을 동적으로 처리하고 그리드로 표시하는 방법:

### 1. Controller 수정

```java
@PostMapping("/process-grid")
public String processInput(@ModelAttribute InputForm inputForm, Model model) {
    // 입력값을 리스트로 변환
    List<String> inputs = Arrays.asList(inputForm.getInput1(), inputForm.getInput2());
    model.addAttribute("inputs", inputs);
    
    // 그리드 데이터 생성 (예시: 2x2 그리드)
    String[][] gridData = {
        {inputForm.getInput1(), inputForm.getInput2()},
        {"처리된 " + inputForm.getInput1(), "처리된 " + inputForm.getInput2()}
    };
    model.addAttribute("gridData", gridData);
    
    return "grid-result";
}
```

### 2. 결과 화면 수정 (동적 그리드)

```html
<!-- grid-result.html에 추가 -->
<h4 class="mt-5 mb-3">동적 그리드 표시</h4>
<table class="table table-bordered text-center">
    <tbody>
        <tr th:each="row : ${gridData}">
            <td th:each="cell : ${row}" th:text="${cell}" style="width: 50%;"></td>
        </tr>
    </tbody>
</table>
```

## 추가 기능 구현

### 1. 입력 유효성 검사

```java
public class InputForm {
    @NotBlank(message = "첫 번째 입력은 필수입니다.")
    private String input1;
    
    @NotBlank(message = "두 번째 입력은 필수입니다.")
    @Size(max=50, message = "50자 이내로 입력해주세요.")
    private String input2;
    
    // getters and setters
}
```

### 2. Controller에 유효성 검사 추가

```java
@PostMapping("/process-grid")
public String processInput(
    @Valid @ModelAttribute InputForm inputForm,
    BindingResult bindingResult,
    Model model) {
    
    if (bindingResult.hasErrors()) {
        return "grid-input";
    }
    
    // 나머지 처리 로직
    return "grid-result";
}
```

### 3. 입력 화면에 에러 메시지 표시

```html
<div class="form-group">
    <label for="input1">첫 번째 입력:</label>
    <input type="text" class="form-control" id="input1" th:field="*{input1}" 
           th:classappend="${#fields.hasErrors('input1')} ? 'is-invalid' : ''">
    <div class="invalid-feedback" th:if="${#fields.hasErrors('input1')}" 
         th:errors="*{input1}"></div>
</div>
```

이렇게 구현하면 TimeLeaf를 사용하여 2개의 입력을 받고 그 결과를 다양한 그리드 형태로 표시할 수 있습니다. 필요에 따라 스타일을 조정하거나 추가 기능을 구현할 수 있습니다.
