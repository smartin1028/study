# 자바에서 압축 파일 해제 및 관리 방법

자바에서 압축 파일을 해제하고, 파일 이름을 변경하며, 해제 후 원본 압축 파일을 삭제하는 방법을 설명드리겠습니다.

## 기본적인 압축 해제 방법

Java에서는 `java.util.zip` 패키지를 사용하여 ZIP 파일을 처리할 수 있습니다.

```java
import java.io.*;
import java.util.zip.ZipEntry;
import java.util.zip.ZipInputStream;

public class ZipExtractor {
    
    public static void extractZipFile(String zipFilePath, String destDirectory) throws IOException {
        File destDir = new File(destDirectory);
        if (!destDir.exists()) {
            destDir.mkdir();
        }
        
        try (ZipInputStream zipIn = new ZipInputStream(new FileInputStream(zipFilePath))) {
            ZipEntry entry = zipIn.getNextEntry();
            
            // 파일명 변경을 위한 카운터
            int fileCounter = 1;
            
            while (entry != null) {
                String originalFileName = entry.getName();
                String newFileName = "renamed_" + fileCounter + "_" + originalFileName;
                String filePath = destDirectory + File.separator + newFileName;
                
                if (!entry.isDirectory()) {
                    extractFile(zipIn, filePath);
                } else {
                    File dir = new File(filePath);
                    dir.mkdir();
                }
                
                zipIn.closeEntry();
                entry = zipIn.getNextEntry();
                fileCounter++;
            }
        }
        
        // 압축 해제 후 원본 ZIP 파일 삭제
        deleteOriginalZipFile(zipFilePath);
    }
    
    private static void extractFile(ZipInputStream zipIn, String filePath) throws IOException {
        try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(filePath))) {
            byte[] bytesIn = new byte[4096];
            int read;
            while ((read = zipIn.read(bytesIn)) != -1) {
                bos.write(bytesIn, 0, read);
            }
        }
    }
    
    private static void deleteOriginalZipFile(String zipFilePath) {
        File zipFile = new File(zipFilePath);
        if (zipFile.exists()) {
            if (zipFile.delete()) {
                System.out.println("원본 ZIP 파일이 성공적으로 삭제되었습니다.");
            } else {
                System.out.println("원본 ZIP 파일 삭제에 실패했습니다.");
            }
        }
    }
    
    public static void main(String[] args) {
        try {
            String zipFilePath = "example.zip";
            String destDirectory = "extracted_files";
            extractZipFile(zipFilePath, destDirectory);
        } catch (IOException ex) {
            ex.printStackTrace();
        }
    }
}
```

## 주요 기능 설명

1. **압축 해제 기능**:
   - `ZipInputStream`을 사용하여 ZIP 파일을 읽습니다.
   - 각 엔트리(파일 또는 디렉토리)를 순회하면서 대상 디렉토리에 추출합니다.

2. **파일 이름 변경**:
   - `ZipEntry`에서 원본 파일 이름을 가져온 후 접두사와 카운터를 추가하여 새 이름을 생성합니다.
   - 예: `document.txt` → `renamed_1_document.txt`

3. **원본 ZIP 파일 삭제**:
   - 압축 해제가 완료된 후 `File.delete()` 메서드를 사용하여 원본 ZIP 파일을 삭제합니다.
