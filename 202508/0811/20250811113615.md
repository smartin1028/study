# 자바에서 압축 파일 해제 및 관리 방법

Java에서 압축 파일을 해제하고, 해제 과정에서 파일 이름을 변경하며, 해제 후 원본 압축 파일을 삭제하는 방법을 설명드리겠습니다.

## 기본적인 압축 해제 방법

Java에서는 `java.util.zip` 패키지를 사용하여 ZIP 파일을 처리할 수 있습니다.

```java
import java.io.*;
import java.util.zip.*;

public class ZipExtractor {
    public static void extractZipFile(String zipFilePath, String destDirectory) throws IOException {
        File destDir = new File(destDirectory);
        if (!destDir.exists()) {
            destDir.mkdir();
        }
        
        try (ZipInputStream zipIn = new ZipInputStream(new FileInputStream(zipFilePath))) {
            ZipEntry entry = zipIn.getNextEntry();
            
            while (entry != null) {
                String filePath = destDirectory + File.separator + entry.getName();
                
                if (!entry.isDirectory()) {
                    extractFile(zipIn, filePath);
                } else {
                    File dir = new File(filePath);
                    dir.mkdir();
                }
                zipIn.closeEntry();
                entry = zipIn.getNextEntry();
            }
        }
    }
    
    private static void extractFile(ZipInputStream zipIn, String filePath) throws IOException {
        try (BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(filePath))) {
            byte[] bytesIn = new byte[4096];
            int read = 0;
            while ((read = zipIn.read(bytesIn)) != -1) {
                bos.write(bytesIn, 0, read);
            }
        }
    }
}
```

## 파일 이름 변경 기능 추가

해제 과정에서 파일 이름을 변경하려면 다음과 같이 수정합니다.

```java
public static void extractZipFileWithRename(String zipFilePath, String destDirectory, 
                                          Map<String, String> renameMap) throws IOException {
    File destDir = new File(destDirectory);
    if (!destDir.exists()) {
        destDir.mkdir();
    }
    
    try (ZipInputStream zipIn = new ZipInputStream(new FileInputStream(zipFilePath))) {
        ZipEntry entry = zipIn.getNextEntry();
        
        while (entry != null) {
            String originalName = entry.getName();
            String newName = renameMap.getOrDefault(originalName, originalName);
            String filePath = destDirectory + File.separator + newName;
            
            // 디렉토리 생성 (필요한 경우)
            new File(filePath).getParentFile().mkdirs();
            
            if (!entry.isDirectory()) {
                extractFile(zipIn, filePath);
            } else {
                File dir = new File(filePath);
                dir.mkdir();
            }
            zipIn.closeEntry();
            entry = zipIn.getNextEntry();
        }
    }
}
```

## 원본 압축 파일 삭제 기능 추가

해제가 완료된 후 원본 압축 파일을 삭제하는 기능을 추가합니다.

```java
public static void extractAndDeleteZip(String zipFilePath, String destDirectory, 
                                     Map<String, String> renameMap) throws IOException {
    try {
        extractZipFileWithRename(zipFilePath, destDirectory, renameMap);
        
        // 압축 해제 성공 후 원본 파일 삭제
        File zipFile = new File(zipFilePath);
        if (zipFile.delete()) {
            System.out.println("원본 압축 파일이 삭제되었습니다.");
        } else {
            System.out.println("원본 압축 파일 삭제에 실패했습니다.");
        }
    } catch (IOException e) {
        System.err.println("압축 해제 중 오류 발생: " + e.getMessage());
        throw e;
    }
}
```

## 추가 고려 사항

1. **안전성 강화**: 파일 삭제 전에 해제가 완료되었는지 확인하는 로직을 추가할 수 있습니다.
2. **다른 압축 형식**: ZIP 외에 GZIP, TAR 등 다른 형식을 처리하려면 Apache Commons Compress 같은 라이브러리를 사용할 수 있습니다.
3. **예외 처리**: 더 세밀한 예외 처리를 추가하여 파일 시스템 문제, 권한 문제 등을 처리할 수 있습니다.
4. **진행 상황 표시**: 큰 파일의 경우 진행 상황을 표시하는 기능을 추가할 수 있습니다.

이 코드는 기본적인 ZIP 파일 처리에 적합하며, 더 복잡한 요구 사항이 있는 경우 Apache Commons Compress 또는 TrueZip 같은 전문 라이브러리를 고려해 볼 수 있습니다.
