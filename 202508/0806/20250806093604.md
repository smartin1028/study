# 자바에서 콘솔로 파이썬 스크립트 실행하는 방법

자바에서 파이썬 스크립트를 실행하는 방법은 여러 가지가 있지만, 가장 일반적인 방법은 `Runtime` 클래스나 `ProcessBuilder` 클래스를 사용하는 것입니다.

## 1. Runtime 클래스 사용

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class RunPython {
    public static void main(String[] args) {
        try {
            // 파이썬 실행 명령어 (python 또는 python3)
            String command = "python3 /path/to/your_script.py arg1 arg2";
            
            // 프로세스 실행
            Process process = Runtime.getRuntime().exec(command);
            
            // 실행 결과 읽기
            BufferedReader reader = new BufferedReader(
                new InputStreamReader(process.getInputStream()));
            
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
            
            // 프로세스 종료 대기
            int exitCode = process.waitFor();
            System.out.println("Exited with code: " + exitCode);
            
        } catch (IOException | InterruptedException e) {
            e.printStackTrace();
        }
    }
}
```

## 2. ProcessBuilder 클래스 사용 (권장)

```java
import java.io.BufferedReader;
import java.io.IOException;
import java.io.InputStreamReader;

public class RunPython {
    public static void main(String[] args) {
        try {
            // 파이썬 실행 명령어와 인자 설정
            ProcessBuilder pb = new ProcessBuilder(
                "python3", "/path/to/your_script.py", "arg1", "arg2");
            
            // 프로세스 시작
            Process process = pb.start();
            
            // 실행 결과 읽기
            BufferedReader reader = new BufferedReader(
                new InputStreamReader(process.getInputStream()));
            
            String line;
            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }
            
            // 에러 스트림 읽기
            BufferedReader errorReader = new BufferedReader(
                new InputStreamReader(process.getErrorStream()));
            
            while ((line = errorReader.readLine()) != null) {
                System.err.println(line);
            }
            
            // 프로세스 종료 대기
            int exitCode = process.waitFor();
            System.out.println("Exited with code: " + exitCode);
            
        } catch (IOException | InterruptedException e) {
            e.printStackTrace();
        }
    }
}
```

## 주의사항

1. **파이썬 경로 확인**: 시스템에 설치된 파이썬 실행 파일 경로가 정확해야 합니다.
   - Windows: `python` 또는 `python.exe`
   - Linux/macOS: `python3` 또는 `/usr/bin/python3`

2. **스크립트 경로**: 절대 경로를 사용하거나, 상대 경로를 사용할 경우 현재 작업 디렉토리를 고려해야 합니다.

3. **환경 변수**: 필요한 경우 `ProcessBuilder`의 `environment()` 메서드로 환경 변수를 설정할 수 있습니다.

4. **인코딩 문제**: 출력 스트림의 인코딩이 일치하지 않을 경우 문제가 발생할 수 있습니다.

5. **실행 권한**: 파이썬 스크립트 파일에 실행 권한이 있는지 확인하세요.

## 더 나은 방법 (Jython 사용)

자바에서 파이썬 코드를 직접 실행하고 싶다면 Jython을 사용할 수도 있습니다. Jython은 자바 가상 머신(JVM)에서 실행되는 파이썬 구현체입니다.

```java
import org.python.util.PythonInterpreter;

public class JythonExample {
    public static void main(String[] args) {
        PythonInterpreter interpreter = new PythonInterpreter();
        interpreter.exec("print('Hello from Python!')");
        interpreter.execfile("/path/to/your_script.py");
    }
}
```

이 방법을 사용하려면 Jython 라이브러리를 프로젝트에 추가해야 합니다.
