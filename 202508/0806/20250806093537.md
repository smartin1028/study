# 자바에서 REST API 호출 방법 및 추천 라이브러리

## 기본적인 REST API 호출 방법

자바에서 REST API를 호출하는 기본적인 방법은 다음과 같습니다:

### 1. HttpURLConnection 사용 (기본 자바 라이브러리)

```java
import java.io.BufferedReader;
import java.io.InputStreamReader;
import java.net.HttpURLConnection;
import java.net.URL;

public class RestApiExample {
    public static void main(String[] args) {
        try {
            URL url = new URL("https://api.example.com/data");
            HttpURLConnection conn = (HttpURLConnection) url.openConnection();
            conn.setRequestMethod("GET");
            
            int responseCode = conn.getResponseCode();
            System.out.println("Response Code: " + responseCode);
            
            BufferedReader in = new BufferedReader(new InputStreamReader(conn.getInputStream()));
            String inputLine;
            StringBuilder response = new StringBuilder();
            
            while ((inputLine = in.readLine()) != null) {
                response.append(inputLine);
            }
            in.close();
            
            System.out.println(response.toString());
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
```

## 추천 라이브러리

### 1. **HttpClient (Java 11 이상)**
- Java 11부터 표준 라이브러리에 포함된 HTTP 클라이언트
- 비동기 요청 지원
- HTTP/2 지원

```java
import java.net.URI;
import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;

public class HttpClientExample {
    public static void main(String[] args) throws Exception {
        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create("https://api.example.com/data"))
                .build();

        HttpResponse<String> response = client.send(
                request, HttpResponse.BodyHandlers.ofString());

        System.out.println(response.body());
    }
}
```

### 2. **RestTemplate (Spring)**
- Spring 프레임워크에서 제공하는 동기식 REST 클라이언트
- 간단한 사용법
- Spring 생태계와 잘 통합됨

```java
import org.springframework.web.client.RestTemplate;

public class RestTemplateExample {
    public static void main(String[] args) {
        RestTemplate restTemplate = new RestTemplate();
        String result = restTemplate.getForObject(
                "https://api.example.com/data", String.class);
        System.out.println(result);
    }
}
```

### 3. **WebClient (Spring WebFlux)**
- Spring 5부터 도입된 비동기, 리액티브 REST 클라이언트
- RestTemplate의 차세대 대체제
- 함수형 스타일 API

```java
import org.springframework.web.reactive.function.client.WebClient;
import reactor.core.publisher.Mono;

public class WebClientExample {
    public static void main(String[] args) {
        WebClient webClient = WebClient.create("https://api.example.com");
        
        Mono<String> result = webClient.get()
                .uri("/data")
                .retrieve()
                .bodyToMono(String.class);
        
        System.out.println(result.block()); // 비동기 결과를 동기적으로 가져옴
    }
}
```

### 4. **Feign Client**
- 선언적 REST 클라이언트
- 인터페이스 기반으로 간단하게 사용 가능
- Netflix에서 개발, Spring Cloud와 통합 가능

```java
@FeignClient(name = "exampleClient", url = "https://api.example.com")
public interface ExampleClient {
    @GetMapping("/data")
    String getData();
}

// 사용 예
@Autowired
private ExampleClient exampleClient;

public void someMethod() {
    String data = exampleClient.getData();
    System.out.println(data);
}
```

### 5. **Retrofit**
- 안드로이드에서 많이 사용되는 타입 안전한 HTTP 클라이언트
- 인터페이스 기반 API 정의
- JSON 매핑이 간편

```java
public interface ApiService {
    @GET("data")
    Call<ResponseBody> getData();
}

// 사용 예
Retrofit retrofit = new Retrofit.Builder()
        .baseUrl("https://api.example.com/")
        .addConverterFactory(GsonConverterFactory.create())
        .build();

ApiService service = retrofit.create(ApiService.class);
Call<ResponseBody> call = service.getData();
Response<ResponseBody> response = call.execute();
System.out.println(response.body().string());
```

### 6. **OkHttp**
- 효율적인 HTTP 클라이언트
- HTTP/2 지원
- 연결 풀링, GZIP 압축 등 지원

```java
OkHttpClient client = new OkHttpClient();

Request request = new Request.Builder()
        .url("https://api.example.com/data")
        .build();

try (Response response = client.newCall(request).execute()) {
    System.out.println(response.body().string());
}
```

## 선택 가이드

1. **Spring 애플리케이션인 경우**: WebClient (비동기) 또는 RestTemplate (동기)
2. **Java 11+ 사용하고 외부 라이브러리 추가를 원하지 않는 경우**: HttpClient
3. **안드로이드 개발**: Retrofit 또는 OkHttp
4. **마이크로서비스 환경**: Feign Client
5. **고성능 비동기 요청 필요**: WebClient 또는 OkHttp

## 추가 고려 사항

- **JSON 처리**: Jackson 또는 Gson 라이브러리와 함께 사용
- **에러 처리**: 각 라이브러리별 예외 처리 방식 이해 필요
- **인증**: OAuth, Basic Auth 등 필요한 인증 방식 지원 확인
- **로깅**: 요청/응답 로깅을 위한 인터셉터 설정 가능

각 라이브러리마다 장단점이 있으므로 프로젝트 요구사항에 맞게 선택하는 것이 중요합니다.
