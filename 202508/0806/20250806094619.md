# Feign Client에서 Header 및 Basic Auth 설정 방법

Feign Client를 사용할 때 헤더 정보와 Basic 인증을 설정하는 방법에 대해 상세히 설명드리겠습니다.

## 1. 기본적인 헤더 설정 방법

### 인터페이스에 직접 @Headers 어노테이션 사용
```java
import feign.Headers;
import feign.Param;
import feign.RequestLine;

@Headers({
    "Content-Type: application/json",
    "X-Custom-Header: my-value"
})
public interface MyApiClient {
    @RequestLine("GET /resource/{id}")
    String getResource(@Param("id") String id);
}
```

### 메소드별 헤더 설정
```java
public interface MyApiClient {
    @RequestLine("GET /resource/{id}")
    @Headers("Authorization: Bearer {token}")
    String getResource(@Param("id") String id, @Param("token") String token);
}
```

## 2. Basic 인증 설정 방법

### 방법 1: @Headers에 직접 인코딩된 값 사용
```java
@Headers("Authorization: Basic {auth}")
public interface MyApiClient {
    @RequestLine("GET /resource")
    String getResource(@Param("auth") String auth);
}

// 사용 시
String auth = Base64.getEncoder().encodeToString("username:password".getBytes());
client.getResource(auth);
```

### 방법 2: RequestInterceptor 사용 (추천)
```java
import feign.RequestInterceptor;
import feign.RequestTemplate;

public class BasicAuthRequestInterceptor implements RequestInterceptor {
    private final String username;
    private final String password;
    
    public BasicAuthRequestInterceptor(String username, String password) {
        this.username = username;
        this.password = password;
    }
    
    @Override
    public void apply(RequestTemplate template) {
        String auth = username + ":" + password;
        String encodedAuth = Base64.getEncoder().encodeToString(auth.getBytes());
        template.header("Authorization", "Basic " + encodedAuth);
    }
}

// Feign 빌더에 인터셉터 추가
MyApiClient client = Feign.builder()
    .requestInterceptor(new BasicAuthRequestInterceptor("user", "pass"))
    .target(MyApiClient.class, "http://api.example.com");
```

### 방법 3: Spring Cloud Feign 사용 시 (application.yml)
```yaml
feign:
  client:
    config:
      default:
        requestInterceptors:
          - com.example.BasicAuthRequestInterceptor
```

## 3. 동적 헤더 설정

### RequestInterceptor를 이용한 동적 헤더 설정
```java
public class DynamicHeaderInterceptor implements RequestInterceptor {
    @Override
    public void apply(RequestTemplate template) {
        // 요청마다 다른 헤더 값을 설정할 수 있음
        template.header("X-Request-ID", UUID.randomUUID().toString());
        
        // 특정 조건에 따라 헤더 추가
        if (template.url().contains("/secure")) {
            template.header("X-Secure-Request", "true");
        }
    }
}
```

## 4. Spring Cloud OpenFeign 사용 시

### @FeignClient와 함께 사용
```java
import org.springframework.cloud.openfeign.FeignClient;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestHeader;

@FeignClient(name = "myService", url = "${api.url}", 
             configuration = FeignConfig.class)
public interface MyServiceClient {
    
    @GetMapping("/endpoint")
    String getData(@RequestHeader("X-Custom-Header") String customHeader);
}

// Configuration 클래스
@Configuration
public class FeignConfig {
    @Bean
    public RequestInterceptor basicAuthRequestInterceptor() {
        return new BasicAuthRequestInterceptor("user", "pass");
    }
    
    @Bean
    public RequestInterceptor customHeaderInterceptor() {
        return template -> template.header("X-Common-Header", "common-value");
    }
}
```

## 5. OAuth2 지원 (Spring Security 사용 시)

```java
@Configuration
public class FeignConfig {
    @Bean
    public RequestInterceptor oauth2FeignRequestInterceptor(
            OAuth2ClientContext oauth2ClientContext,
            OAuth2ProtectedResourceDetails resource) {
        return new OAuth2FeignRequestInterceptor(oauth2ClientContext, resource);
    }
}
```

## 주의사항

1. Basic Auth는 HTTPS를 사용할 때만 안전합니다.
2. 민감한 정보는 절대로 코드에 하드코딩하지 마세요. 환경 변수나 설정 파일에서 읽어오는 것이 좋습니다.
3. 여러 인터셉터를 등록하면 등록 순서대로 적용됩니다.
4. Spring Cloud Feign을 사용하면 자동으로 Spring MVC 어노테이션(@RequestMapping 등)을 사용할 수 있습니다.

이러한 방법들을 조합하면 Feign Client를 사용할 때 다양한 인증 및 헤더 설정이 가능합니다.
